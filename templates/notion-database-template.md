# Notion データベーステンプレート設定

## 1. 新しいデータベースを作成

1. Notionで新しいページを作成
2. `/database` と入力してデータベースを選択
3. 「Table - Inline」を選択
4. タイトルを「Trade Journal」に設定

## 2. プロパティの設定

以下のプロパティ（列）を追加してください：

### 必須プロパティ

| プロパティ名 | タイプ | 設定 |
|-------------|--------|------|
| **タイトル** | Title | デフォルトのまま（通貨ペア + 日付が自動入力されます） |
| 日時 | Date | タイムゾーン: Asia/Tokyo |
| 通貨ペア | Select | オプション: USD/JPY, EUR/USD, GBP/JPY, など |
| 方向 | Select | オプション: 買い, 売り |
| エントリー | Number | - |
| エグジット | Number | - |
| ロット | Number | - |
| 損益 | Number | 小数点以下: 2桁 |
| 通貨 | Select | オプション: JPY, USD, EUR, など |
| Pips | Number | 小数点以下: 1桁 |
| 結果 | Select | オプション: 勝ち, 負け |
| 感情 | Select | オプション: 冷静, 焦り, 不安, 自信, など |
| タグ | Multi-select | オプション: デイトレード, スイング, スキャルピング, トレンドフォロー, レンジ, 反省, 成功, など |
| チャート画像 | URL | - |

### オプショナルプロパティ（推奨）

| プロパティ名 | タイプ | 設定 |
|-------------|--------|------|
| ストップロス | Number | - |
| テイクプロフィット | Number | - |
| リスクリワードレシオ | Formula | `prop("テイクプロフィット") - prop("エントリー")) / (prop("エントリー") - prop("ストップロス")` |
| 勝率（個別） | Formula | `if(prop("結果") == "勝ち", "✅", "❌")` |
| 作成日 | Created time | - |
| 最終更新日 | Last edited time | - |

## 3. ビューの設定

複数のビューを作成して、異なる視点からデータを確認できます：

### デフォルトビュー（テーブル）
- すべてのプロパティを表示
- 日時の降順でソート

### カレンダービュー
1. 「+ Add a view」をクリック
2. 「Calendar」を選択
3. 名前: 「カレンダー」
4. 日時プロパティを選択
5. カードプレビュー: 通貨ペア、結果、損益を表示

### ボードビュー（通貨ペア別）
1. 「+ Add a view」をクリック
2. 「Board」を選択
3. 名前: 「通貨ペア別」
4. グループ化: 通貨ペア
5. カードプレビュー: 日時、結果、損益

### タイムラインビュー
1. 「+ Add a view」をクリック
2. 「Timeline」を選択
3. 名前: 「タイムライン」
4. 日時プロパティを選択

## 4. フィルターの設定例

### 勝ちトレードのみ表示
- 結果 = 勝ち

### 今週のトレード
- 日時 is within → This week

### 損失トレードの反省
- 結果 = 負け
- ソート: 損益の昇順

### 特定通貨ペア
- 通貨ペア = USD/JPY

## 5. テンプレートの作成

データベース内でテンプレートを作成すると、手動入力時に便利です：

1. データベースの右上「⌄」→「Templates」
2. 「+ New template」
3. テンプレート名: 「トレード記録」
4. 以下のセクションを追加：

```
## トレード概要
- 通貨ペア:
- 方向:
- エントリー理由:

## エグジット理由
-

## 反省点・学び
-

## チャート分析
[画像を挿入]

## 次回への改善点
-
```

## 6. 条件付き書式（データベースプロパティの色分け）

### 結果プロパティ
- 「勝ち」: 緑色
- 「負け」: 赤色

### 感情プロパティ
- 「冷静」: 青色
- 「焦り」: オレンジ色
- 「不安」: グレー色
- 「自信」: 緑色

### タグプロパティ
- 「成功」: 緑色
- 「反省」: 赤色
- 「デイトレード」: 青色
- 「スキャルピング」: 紫色
- 「スイング」: オレンジ色

## 7. データベースIDの取得

n8nで使用するため、NotionデータベースのIDを取得します：

### 方法1: URLから取得
データベースページを開いたときのURLから：
```
https://www.notion.so/【ここがデータベースID（32文字）】?v=...
```

### 方法2: Share menuから
1. データベースの「Share」ボタンをクリック
2. 「Copy link」でURLをコピー
3. URLからIDを抽出

取得したIDを`workflows/trade-journal-main.json`の`YOUR_NOTION_DATABASE_ID`の部分に設定します。

## 8. Notion統合の設定

n8nからアクセスするために、Notion統合を作成する必要があります：

1. https://www.notion.so/my-integrations にアクセス
2. 「+ New integration」をクリック
3. 名前: 「Trade Journal n8n」
4. ワークスペースを選択
5. 「Submit」をクリック
6. 「Internal Integration Token」をコピー（これをn8nの認証情報に使用）

### データベースに統合を接続
1. Trade Journalデータベースページを開く
2. 右上の「⋮」→「Connections」→「Connect to」
3. 作成した統合「Trade Journal n8n」を選択

## 9. サンプルページ

手動で1つサンプルページを作成してテストしてください：

**タイトル**: USD/JPY - 買い (2025-11-09)

**プロパティ**:
- 日時: 2025-11-09 15:30
- 通貨ペア: USD/JPY
- 方向: 買い
- エントリー: 149.50
- エグジット: 149.85
- ロット: 1.0
- 損益: 3500
- 通貨: JPY
- Pips: 35
- 結果: 勝ち
- 感情: 冷静
- タグ: デイトレード, トレンドフォロー, 成功

**本文**:
```
## トレード概要
上昇トレンド継続中。レジスタンスブレイクでエントリー。

## エグジット理由
利確目標手前で反転の兆しがあったため早めに決済。

## 反省点・学び
早めの決済判断が良かった。欲張らずに利益確定できた。
```

## 10. ダッシュボードの作成（上級）

別ページに「トレードダッシュボード」を作成し、以下を配置：

1. **リンクドデータベース**: Trade Journalへのリンク
2. **週間サマリー**: フィルター「This week」を適用
3. **月間サマリー**: フィルター「This month」を適用
4. **統計ブロック**: 手動で以下を記載
   - 総トレード数
   - 勝率
   - 総損益
   - 最高/最低トレード

## トラブルシューティング

### n8nからページが作成できない場合
1. Notion統合が正しく設定されているか確認
2. データベースに統合を接続したか確認
3. n8nの認証情報でIntegration Tokenを使用しているか確認

### プロパティ名が一致しない場合
- n8nワークフローのプロパティ名とNotionのプロパティ名が完全一致しているか確認
- 大文字小文字、スペースの有無に注意

### Selectプロパティでエラーが出る場合
- n8nから送信する値が、Notionのプロパティオプションに存在するか確認
- 新しいオプションを追加する場合は、先にNotion側で手動追加が必要
