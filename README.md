# ゴトー日仲値トレードEA (GotobiNakaneEA)

**MT5対応 Fintokeiチャレンジプラン専用EA**

## 概要

ゴトー日（5日、10日、15日、20日、25日、30日）の仲値（9:55）に向けたドル買いアノマリーを利用した自動売買EAです。月末のリバランスアノマリーも組み合わせ、チャンスを最大化します。

## リサーチ結果に基づくロジック

### 仲値トレードの背景

- **実需ベース**: 日本の輸入企業がゴトー日に決済用ドルを調達するため、9:55の仲値に向けてドル買いが発生
- **勝率**: 研究論文によると約60-66%（特に金曜日のゴトー日で高い）
- **エビデンス**: 茨城大学・神戸大学等の研究で統計的に有意と確認

### 採用している4つのロジック

| ロジック | 内容 | エントリー | 決済 | 条件 |
|----------|------|-----------|------|------|
| ロジック1 | 仲値ロング | 3:55 BUY | 9:55 | ゴトー日 |
| ロジック2 | 仲値ショート | 9:55 SELL | 10:25 | ゴトー日 |
| ロジック3-A | 月末SELL | 9:55 SELL | 15:00 | 月末日 |
| ロジック3-B | 月末BUY | 16:00 BUY | 23:00 | 月末日 |

## Fintokei対応の資金管理

### 損失制限ロジック

1. **1日の最大損失率**: 4.9%（5%ルール遵守のため余裕を持たせる）
   - UTC 0時（日本時間9時）に有効証拠金を記録
   - 含み損も含めてリアルタイム監視
   - 90%到達で警告＆最大損失ポジション自動決済

2. **全体の最大損失率**: 9.9%（10%ルール遵守）
   - 初期資金を基準に固定計算
   - 含み損でも失格のため厳格管理

3. **トレードリスク制限**: 最大3%/トレード
   - 高ロット戦略に対応しつつリスク分散

### ロットサイズ計算

- 損切り幅に基づいて最適ロットを自動計算
- エントリーポイントを損切りラインに近づけることで高ロット化可能
- ブローカーの最小/最大ロット制限を自動考慮

## 推奨通貨ペア

### USDJPY（推奨）
- 仲値アノマリーの王道対象
- 実需に基づく信頼性の高い動き
- 研究論文での検証済み

### XAUUSD（ゴールド）
- 仲値アノマリーの直接対象ではない
- USD相関での動きを狙う
- 東京セッションは低ボラティリティ（20-40pips）
- レンジブレイク戦略向き

**結論**: USDJPYを主軸とし、XAUUSDは補助的に使用することを推奨

## インストール方法

1. `GotobiNakaneEA.mq5` を `MT5/MQL5/Experts/` フォルダにコピー
2. `Presets/` フォルダの .set ファイルを `MT5/MQL5/Presets/` にコピー
3. MT5でコンパイル（F7キー）
4. チャートにEAをドラッグ＆ドロップ

## パラメータ設定

### 基本設定
| パラメータ | 説明 | デフォルト |
|-----------|------|-----------|
| InitialBalance | 初期資金（0=自動検出） | 0 |
| DailyLossLimit | 1日最大損失率(%) | 4.9 |
| TotalLossLimit | 全体最大損失率(%) | 9.9 |
| MaxRiskPerTrade | 1トレードリスク(%) | 2.0 |
| MagicNumber | マジックナンバー | 20251222 |

### タイムゾーン設定
| パラメータ | 説明 | デフォルト |
|-----------|------|-----------|
| ServerGMTOffset | サーバーGMTオフセット | 2 |
| JapanGMTOffset | 日本のGMTオフセット | 9 |

**重要**: ブローカーのサーバー時間を確認し、`ServerGMTOffset` を正しく設定してください。
- 多くのブローカー: GMT+2（冬時間）/ GMT+3（夏時間）
- 一部のブローカー: GMT+0

### フィルター設定
| パラメータ | 説明 | デフォルト |
|-----------|------|-----------|
| FridayGotobiOnly | 金曜日のゴトー日のみ | false |
| SkipHolidayGotobi | 土日ゴトー日は前日金曜に取引 | true |

## トレードスケジュール例

### 通常のゴトー日
```
03:55  BUYエントリー（ロジック1）
       ↓ 約6時間ホールド
09:55  決済 → すぐSELLエントリー（ロジック2）
       ↓ 30分ホールド
10:25  決済
```

### 月末アノマリー日
```
03:55  BUY（ロジック1）
09:55  決済 → SELL（ロジック2・3-A）
10:25  ロジック2決済
15:00  ロジック3-A決済
16:00  BUY（ロジック3-B）
23:00  決済
```

## 注意事項

1. **バックテスト推奨**: 本番前に必ずストラテジーテスターで検証
2. **デモ口座で確認**: サーバー時間のオフセットを確認
3. **ファンダメンタルズ確認**: 重要指標発表日は注意
4. **NY市場の状況**: 前日のNY市場が大荒れの場合は注意
5. **取引の再現性**: 一貫性のある取引パターンを維持
