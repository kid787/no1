# MT5 グランビルの法則 トレーディングシステム

このリポジトリには、グランビルの法則（Granville's Law）に基づいたMT5（MetaTrader 5）用のカスタムインジケーターとエキスパートアドバイザー（EA）が含まれています。

## 📁 プロジェクト構成

```
no1/
├── Indicators/
│   └── GranvilleMA.mq5        # カスタムインジケーター
├── Experts/
│   └── GranvilleEA.mq5        # エキスパートアドバイザー（自動売買EA）
└── README.md                   # このファイル
```

## 🎯 システム概要

### 1. カスタムインジケーター（GranvilleMA.mq5）

**目的**: H1（1時間足）チャート上で、グランビルの法則に基づく移動平均線（MA）の配置、長期トレンドの方向性、およびエントリーポイントを視覚的に表示します。

#### 主な機能

- **中期・長期MA表示**
  - 75 EMA（中期MA）：H1チャートでの押し目/戻りの基準線
  - 200 EMA（長期MA）：長期トレンドフィルター

- **MTFトレンド表示**
  - 画面右上に、H4（4時間足）の75 EMAの傾きを表示
  - 上昇トレンド: 「H4トレンド: ⬆️上昇 (BUY優先)」（緑色）
  - 下降トレンド: 「H4トレンド: ⬇️下落 (SELL優先)」（赤色）
  - レンジ相場: 「H4トレンド: レンジ (トレード非推奨)」（黄色）

- **グランビルサイン（Rule 3/7）**
  - Rule 3（買いシグナル）: 上昇トレンド中の押し目を青いドットで表示
  - Rule 7（売りシグナル）: 下降トレンド中の戻りを赤いドットで表示

- **平均足（Heikin-Ashi）オーバーレイ**
  - ローソク足のノイズを平滑化した平均足を半透明で表示
  - 陽線: 緑色、陰線: 赤色

#### パラメータ設定

| パラメータ名 | デフォルト値 | 説明 |
|------------|------------|------|
| MA_PERIOD_MID | 75 | 中期MA期間 |
| MA_PERIOD_LONG | 200 | 長期MA期間 |
| MA_METHOD | EMA | MA計算方法（EMA推奨） |
| MTF_TREND_PERIOD | H4 | MTFトレンド確認用時間足 |
| HEIKIN_ASHI_ENABLED | true | 平均足表示の有効/無効 |
| MA_PROXIMITY_PIPS | 50 | MA近接判定（Pips） |

---

### 2. エキスパートアドバイザー（GranvilleEA.mq5）

**目的**: XAU/USD（金）のH1チャートにおいて、MTFトレンドフィルターと中期MA（75 EMA）に基づくグランビルの法則（Rule 3/7）の順張りシグナルを自動売買します。

#### 取引ロジック

**A. トレンド/環境認識（MTFフィルタリング）**
- H4の75 EMAの傾き（20本前との比較）で長期トレンドを判定
- H1の75 EMAの傾きで中期トレンドを確認
- 両方が同じ方向の場合のみエントリーを検討

**B. エントリーシグナル**

1. **買いエントリー（Rule 3: 押し目買い）**
   - H4 EMA 75が上向き（上昇トレンド）
   - H1 EMA 75が上向き
   - 前足がEMA 75に接近（設定範囲内）
   - 現在足がEMA 75から反発
   - 短期EMA 20が上向きに転じている

2. **売りエントリー（Rule 7: 戻り売り）**
   - H4 EMA 75が下向き（下降トレンド）
   - H1 EMA 75が下向き
   - 前足がEMA 75に接近（設定範囲内）
   - 現在足がEMA 75から反落
   - 短期EMA 20が下向きに転じている

**C. リスク管理**
- **損切り（SL）**: 直近のスイングロー/ハイに設定（最大幅は StopLoss_Pips）
- **利益確定（TP）**: SL幅 × TakeProfit_Ratio（デフォルト: 1:2のリスクリワード比率）

#### パラメータ設定

| パラメータ名 | デフォルト値 | 説明 |
|------------|------------|------|
| Symbol_to_Trade | "XAUUSD" | 取引対象銘柄 |
| Trade_Lots | 0.01 | 取引ロット数 |
| MA_Period_Mid | 75 | H1中期MA期間 (EMA) |
| MA_Period_Long | 200 | H1長期MA期間 (EMA) |
| MTF_Timeframe | H4 | MTFトレンド確認用時間足 |
| MA_Proximity_Pips | 100 | MA近接許容範囲 (Point単位) |
| StopLoss_Pips | 200 | 損切り幅 (Point単位) |
| TakeProfit_Ratio | 2.0 | リスクリワード比率（1:2） |
| EMA_Short_Period | 20 | 短期EMA（反発/反落確認用） |
| Magic_Number | 123456 | マジックナンバー |

## 🚀 インストール方法

### カスタムインジケーターのインストール

1. MT5を起動します
2. `ファイル` → `データフォルダを開く` をクリック
3. `MQL5` → `Indicators` フォルダを開きます
4. `GranvilleMA.mq5` をこのフォルダにコピーします
5. MT5のメタエディターで `GranvilleMA.mq5` を開き、コンパイル（F7キー）します
6. MT5のナビゲーターウィンドウの「インジケーター」から「GranvilleMA」をチャートにドラッグ＆ドロップします

### EAのインストール

1. MT5を起動します
2. `ファイル` → `データフォルダを開く` をクリック
3. `MQL5` → `Experts` フォルダを開きます
4. `GranvilleEA.mq5` をこのフォルダにコピーします
5. MT5のメタエディターで `GranvilleEA.mq5` を開き、コンパイル（F7キー）します
6. MT5のナビゲーターウィンドウの「エキスパートアドバイザー」から「GranvilleEA」をチャートにドラッグ＆ドロップします
7. **重要**: EAを実行する前に、MT5の右上にある「自動売買」ボタンをクリックして有効にしてください

## ⚙️ 使用方法

### カスタムインジケーター

1. XAU/USDのH1チャートを開きます
2. ナビゲーターから「GranvilleMA」をチャートにドラッグ
3. パラメータを必要に応じて調整します
4. 「OK」をクリックして適用します

**チャート表示内容:**
- 青色の線: 75 EMA（中期MA）
- 赤色の線: 200 EMA（長期MA）
- 青い矢印: 買いシグナル（Rule 3）
- 赤い矢印: 売りシグナル（Rule 7）
- 緑/赤のキャンドル: 平均足（オプション）
- 右上のテキスト: H4トレンド方向

### EA（自動売買）

1. XAU/USDのH1チャートを開きます
2. ナビゲーターから「GranvilleEA」をチャートにドラッグ
3. パラメータを設定します:
   - **取引ロット数**: リスク許容度に応じて設定
   - **StopLoss_Pips**: 損切り幅（デフォルト: 200 = 20.0 Pips）
   - **TakeProfit_Ratio**: リスクリワード比率（デフォルト: 2.0）
4. 「自動売買を許可する」にチェックを入れます
5. 「OK」をクリックして適用します
6. MT5の右上にある「自動売買」ボタンが緑色になっていることを確認します

**EA動作条件:**
- H1ローソク足の確定時にのみシグナルをチェック
- 既存のポジションがある場合は新規エントリーしない
- レンジ相場と判断された場合はエントリーを控える

## ⚠️ 重要な注意事項

### リスク警告

1. **バックテスト必須**: 実資金で運用する前に、必ず十分なバックテストとデモ取引を行ってください
2. **資金管理**: 取引ロット数は、口座残高の1-2%のリスクを超えないように設定してください
3. **市場環境**: このシステムはトレンド相場で最も効果的です。レンジ相場では性能が低下する可能性があります
4. **スプレッド**: XAUUSDは特にスプレッドが変動しやすいため、ブローカーのスプレッド条件を確認してください
5. **VPS推奨**: 24時間安定した取引を行うには、VPS（仮想プライベートサーバー）の使用を推奨します

### システム要件

- MetaTrader 5（ビルド 3000以降）
- XAUUSDの取引が可能なブローカー口座
- 安定したインターネット接続

## 🔧 トラブルシューティング

### インジケーターが表示されない

- メタエディターでコンパイルエラーがないか確認してください
- MT5を再起動してみてください
- チャートの時間足がH1であることを確認してください

### EAが取引しない

- 「自動売買」ボタンが有効（緑色）になっているか確認してください
- エキスパートタブでエラーメッセージを確認してください
- パラメータ設定（特にMA_Proximity_Pips）が厳しすぎないか確認してください
- H4とH1のトレンドが一致していない可能性があります

### SLやTPが設定されない

- ブローカーの最小SL/TP距離を確認してください
- StopLoss_Pipsの値を調整してみてください

## 📊 パフォーマンス最適化のヒント

1. **MA_Proximity_Pips**: この値を調整することで、エントリーの頻度を変更できます
   - 値を大きくする: エントリー機会が増加（精度は低下）
   - 値を小さくする: エントリー機会が減少（精度は向上）

2. **TakeProfit_Ratio**: リスクリワード比率を調整
   - 2.0以上を推奨（1:2のリスクリワード）
   - より保守的な取引には3.0以上を検討

3. **MTF_Timeframe**: 上位足の時間軸を変更
   - H4（デフォルト）: バランス型
   - Daily: より保守的（長期トレンド重視）
   - H1: より積極的（短期トレンド重視）
