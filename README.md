# MTF Conscious Line Detector for MT5

MT5用マルチタイムフレーム水平線・ネックライン検出インジケーター

## 概要

**MTF Conscious Line Detector** は、複数の上位時間足で「意識されている」重要な水平線（サポート/レジスタンス）とトレンド転換パターンのネックラインを自動検出し、現在のチャート（1分足推奨）に描画する高精度インジケーターです。

## 主要機能

### 1. マルチタイムフレーム対応（8つの時間足）
- 月足（MN1）
- 週足（W1）
- 日足（D1）
- 4時間足（H4）
- 1時間足（H1）
- 30分足（M30）
- 15分足（M15）
- 5分足（M5）

### 2. 高精度な水平線検出
- **ピボットベース検出**: 左右N期間で高値/安値が更新されていない重要なレベルを自動検出
- **終値基準の判定**: ローソク足の終値を基準に、ラインの有効性を判断
- **ヒゲの活用**: ヒゲは「リジェクション（反発）」の証拠として評価

### 3. ラインの強度評価（10段階）
トライ回数（価格がラインに到達し反発した回数）に基づき、ラインの信頼性をスコア化：

- **リジェクション判定**: 価格がゾーンに到達後、終値がゾーン外で反転
- **極性転換検出**: レジスタンス→サポート、またはサポート→レジスタンスへの転換を検出（強度+3）
- **視覚化**:
  - 色: ライトグレー（弱）→ ブルー → ゴールド → レッド（最強）
  - 太さ: トライ回数が多いほど太いライン（1-5段階）
  - 極性転換: マゼンタ色で表示

### 4. パターン認識とネックライン検出
以下のトレンド転換パターンを自動検出し、ネックラインを描画：

- **Mパターン（ダブルトップ）**: 2つの高値が近い場合、中間の安値をネックラインとして描画
- **Wパターン（ダブルボトム）**: 2つの安値が近い場合、中間の高値をネックラインとして描画
- **ヘッドアンドショルダー**: 左肩-ヘッド-右肩パターンを検出し、ネックラインを描画
- **スタイル**: 点線（STYLE_DOT）、黄色で表示

### 5. ラベル表示
各ラインに以下の情報を表示：
- 時間足（例: H4, D, W）
- タイプ（S: サポート, R: レジスタンス, NL: ネックライン）
- トライ回数（例: 5x）
- 極性転換の有無

例: `H4-R:5x [極性転換]`

### 6. パフォーマンス最適化
- **計算範囲の制限**: デフォルトで過去500足のみ分析（調整可能）
- **ライン数の制限**: 時間足あたり最大10本まで（調整可能）
- **効率的なMTFデータ取得**: `CopyHigh/Low/Close` 関数で必要なデータのみ取得
- **自動クリーンアップ**: 古いオブジェクトを自動削除し、チャートの負荷を軽減

## インストール方法

1. **ファイルのコピー**
   ```
   Indicators/MTF_Conscious_Line_Detector.mq5
   ```
   を MetaTrader 5 の `MQL5/Indicators/` フォルダにコピー

2. **コンパイル**
   - MetaEditor を開く
   - `MTF_Conscious_Line_Detector.mq5` を開く
   - F7 キーを押してコンパイル

3. **チャートに適用**
   - MT5のナビゲーターウィンドウから「インジケーター」→「カスタム」を開く
   - `MTF Conscious Line Detector` をチャートにドラッグ＆ドロップ

## パラメーター設定

### 基本設定
- **InpPivotPeriod** (デフォルト: 5)
  - ピボット検出期間（左右の期間数）
  - 値を大きくすると、より重要なレベルのみ検出

- **InpLookbackBars** (デフォルト: 500)
  - 計算対象の過去足数
  - パフォーマンスと精度のバランスを調整

- **InpZoneWidthPips** (デフォルト: 5.0)
  - ラインタッチ判定のゾーン幅（pips）
  - ボラティリティに応じて調整

- **InpMinTryCount** (デフォルト: 1)
  - 表示する最小トライ回数
  - 値を大きくすると、より信頼性の高いラインのみ表示

- **InpMaxLinesPerTF** (デフォルト: 10)
  - 時間足あたりの最大ライン数
  - 表示を絞り込みたい場合は減らす

### 表示設定（各時間足の ON/OFF）
- **InpShowMonthly** (デフォルト: true) - 月足ライン
- **InpShowWeekly** (デフォルト: true) - 週足ライン
- **InpShowDaily** (デフォルト: true) - 日足ライン
- **InpShow4H** (デフォルト: true) - 4時間足ライン
- **InpShow1H** (デフォルト: true) - 1時間足ライン
- **InpShow30M** (デフォルト: true) - 30分足ライン
- **InpShow15M** (デフォルト: true) - 15分足ライン
- **InpShow5M** (デフォルト: true) - 5分足ライン
- **InpShowNecklines** (デフォルト: true) - ネックライン表示
- **InpShowLabels** (デフォルト: true) - ラベル表示

## 使い方

### 基本的な使い方
1. 1分足チャートに適用（推奨）
2. 複数の時間足のラインが自動描画される
3. ラインの色と太さで強度を確認
4. ラベルで詳細情報を確認

### トレード活用例
1. **エントリーポイントの判断**
   - 強いライン（青、ゴールド、レッド）での反発を狙う
   - ネックライン（黄色点線）のブレイクでエントリー

2. **損切りラインの設定**
   - サポート/レジスタンスラインの外側に設定

3. **利確目標の設定**
   - 次の強いライン（複数のトライがあるライン）を目標に設定

4. **ダマシの回避**
   - ヒゲだけのタッチは反発の可能性が高い
   - 実体抜けを確認してからエントリー

### 推奨設定（通貨ペア・時間軸別）

#### スキャルピング（1分足）
```
InpPivotPeriod = 3
InpLookbackBars = 300
InpZoneWidthPips = 3.0
InpShow5M = true
InpShow15M = true
InpShow30M = true
他の上位足は false
```

#### デイトレード（5分足・15分足）
```
InpPivotPeriod = 5
InpLookbackBars = 500
InpZoneWidthPips = 5.0
InpShow30M = true
InpShow1H = true
InpShow4H = true
InpShowDaily = true
```

#### スイングトレード（1時間足・4時間足）
```
InpPivotPeriod = 7
InpLookbackBars = 1000
InpZoneWidthPips = 10.0
InpShow4H = true
InpShowDaily = true
InpShowWeekly = true
InpShowMonthly = true
```

## 技術仕様

### ロジックの詳細

#### 1. ピボット検出
```
ピボットハイ: 左右N期間で最も高い高値
ピボットロー: 左右N期間で最も低い安値
```

#### 2. トライカウント計算
```
初期値: 1（検出時）
リジェクション: +1（ゾーンタッチ後、終値が反転）
極性転換: +3（レジスタンス→サポートまたはその逆）
```

#### 3. ゾーン判定
```
上限ゾーン = ライン価格 + ゾーン幅
下限ゾーン = ライン価格 - ゾーン幅
タッチ判定 = 高値 >= 下限ゾーン AND 安値 <= 上限ゾーン
```

#### 4. 色の段階（10段階）
| トライ回数 | 色 | 説明 |
|-----------|--------|------|
| 1-2 | ライトグレー | 弱いライン |
| 3-4 | シルバー | やや弱い |
| 5-6 | ライトブルー | 普通 |
| 7-8 | ドジャーブルー | やや強い |
| 9-10 | ブルー | 強い |
| 11-12 | ミディアムブルー | かなり強い |
| 13-14 | ネイビー | 非常に強い |
| 15-16 | ゴールド | 上位足・高強度 |
| 17-18 | オレンジ | 極めて強い |
| 19+ | レッド | 最強 |
| 極性転換 | マゼンタ | 特別（強度問わず） |

## トラブルシューティング

### ラインが表示されない場合
1. 各時間足の表示設定を確認（InpShowXXX）
2. `InpMinTryCount` を下げる（1に設定）
3. `InpLookbackBars` を増やす（1000に設定）
4. チャートの時間足が適切か確認（1分足推奨）

### パフォーマンスが悪い場合
1. `InpLookbackBars` を減らす（300に設定）
2. `InpMaxLinesPerTF` を減らす（5に設定）
3. 表示する時間足を絞る（上位足のみON）
4. `InpMinTryCount` を上げる（2-3に設定）

### ラインが多すぎる場合
1. `InpMinTryCount` を上げる（3-5に設定）
2. `InpMaxLinesPerTF` を減らす（5に設定）
3. 不要な時間足をOFFにする
4. `InpPivotPeriod` を大きくする（7-10に設定）

## 注意事項

1. **バックテスト非対応**: このインジケーターはリアルタイム表示専用です
2. **計算負荷**: 複数の時間足を同時に表示すると、低スペックPCでは動作が重くなる可能性があります
3. **ラインの更新**: 新しいバーが形成されるたびに再計算されます
4. **ダマシ**: 全てのラインが機能するわけではありません。他のテクニカル指標と併用してください
