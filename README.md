# N-Zone Hunter - XAUUSD N字波動ゾーン取引システム

MT5用の高度なN字波動検出とゾーン取引システム

## 概要

N-Zone Hunterは、XAUUSD（ゴールド）専用に設計された自動売買システムです。1時間足（H1）で健全なN字波動パターンを検出し、フィボナッチ・エクステンションで計算されたターゲットゾーン（TPゾーン）での反転を狙います。

## 主な特徴

### 📊 H1時間足での分析
- **N字波動検出**: A→B→C→Dの明確なN字パターンを自動検出
- **健全性フィルター**: フィボナッチ・リトレースメント38.2%〜61.8%の範囲内の調整波のみを対象
- **TPゾーン計算**:
  - TP1: 100%エクステンション（N値）
  - TP2: 161.8%フィボナッチ・エクステンション

### 🎯 M1時間足でのエントリー
- **反転プライスアクション検出**:
  - ピンバー（長いヒゲ）
  - エンゴルフィング（包み足）
  - ミニN字波動の転換構造
- **逆張り戦略**: TPゾーン到達後の反転を狙う高確率エントリー

### 💰 リスク管理
- **自動ロットサイズ計算**: 口座残高の1%（設定可能）リスクに基づく
- **ストップロス**: エントリー足の反転を否定する直近の安値/高値
- **テイクプロフィット**: 最低1:2のリスクリワード比率を確保

```

├── Indicators/
│   └── NZoneHunter.mq5          # インジケーター（H1でN字波動とTPゾーンを表示）
├── Experts/
│   └── NZoneHunterEA.mq5        # EA（M1で自動取引を実行）
```

## インストール方法

1. **ファイルのコピー**:
   - `Include/NZoneCommon.mqh` → `MQL5/Include/`
   - `Indicators/NZoneHunter.mq5` → `MQL5/Indicators/`
   - `Experts/NZoneHunterEA.mq5` → `MQL5/Experts/`

2. **コンパイル**:
   - MetaEditor（F4）を開く
   - 各ファイルを開いてコンパイル（F7）

3. **チャートに適用**:
   - インジケーター: H1チャートに適用してN字波動を視覚化
   - EA: M1チャートに適用して自動取引を実行

## 使用方法

### インジケーター
1. XAUUSDのH1チャートを開く
2. インジケーター「NZoneHunter」を適用
3. N字波動パターンとTPゾーンが自動的に描画される

### EA（自動取引）
1. XAUUSDのM1チャートを開く
2. EA「NZoneHunterEA」を適用
3. パラメータを調整（推奨: リスク1%、R:R 2.0）
4. 自動売買を有効化

## 取引ロジック

1. **H1分析**: N字波動（A→B→C）を検出し、TPゾーン（TP1〜TP2）を計算
2. **ゾーン監視**: M1で価格がTPゾーンに侵入するまで待機
3. **反転確認**: ゾーン内で反転プライスアクションを検出
4. **エントリー**: 逆張りでポジションを建てる
5. **決済**: SL（反転否定ポイント）とTP（R:R 1:2以上）を設定
