# FX Price Action Indicator for MT5

MT5用のプライスアクションLONGエントリー検出カスタムインジケーター

## 概要

このインジケーターは、4時間足の抵抗帯付近で発生する1分足の「下落の勢いの衰え」と「強い上昇への転換」を検出し、LONGエントリーのタイミングを視覚的に通知します。

## 機能

- **3フェーズ検出システム**
  - フェーズ1: 抵抗帯内での値動きの確認
  - フェーズ2: 下落の勢いの衰えの確認
  - フェーズ3: 強い反発（上昇への転換）の確認

- **視覚的なシグナル**
  - エントリーポイントに上向きの矢印（ライムグリーン）を表示
  - ストップロス推奨位置に赤い破線を表示

## インストール方法

1. `Indicators/PA_Entry_Long_Indicator.mq5` をMT5の `MQL5/Indicators/` フォルダーにコピー
2. MT5のナビゲーターウィンドウでインジケーターをコンパイル
3. チャートにドラッグ&ドロップして適用

## 設定パラメーター

### 必須パラメーター

- **Zone_High** (デフォルト: 1.1000)
  - 検出対象とする4時間抵抗帯の上限価格

- **Zone_Low** (デフォルト: 1.0950)
  - 検出対象とする4時間抵抗帯の下限価格

- **Lookback_Period_Decline** (デフォルト: 10)
  - 過去の下落の勢いを評価する期間（ローソク足本数）

- **Momentum_Threshold** (デフォルト: 0.0010)
  - 上昇の勢いを「強い」と判断するためのローソク足実体の大きさの基準（pips）

- **Angle_Period** (デフォルト: 5)
  - 値動きの角度を計算するためのローソク足の期間

### 詳細設定パラメーター

- **Small_Body_Period** (デフォルト: 3)
  - 小さな実体の評価期間

- **Small_Body_Ratio** (デフォルト: 0.3)
  - 小さな実体と判断する比率（平均実体サイズに対する割合）

- **Vertical_Angle_Threshold** (デフォルト: 60.0)
  - 垂直と判断する角度（度数）

- **Gentle_Angle_Threshold** (デフォルト: 45.0)
  - 緩やかと判断する角度（度数）

- **Upper_Wick_Ratio** (デフォルト: 0.3)
  - ヒゲが少ないと判断する比率（実体サイズに対する上ヒゲの割合）

- **Strong_Candle_Lookback** (デフォルト: 2)
  - 強い陽線の確認期間

## 使用方法

1. **抵抗帯の設定**
   - 4時間足チャートで抵抗帯を特定
   - `Zone_High` と `Zone_Low` を抵抗帯の範囲に設定

2. **1分足チャートに適用**
   - インジケーターを1分足チャートに適用
   - パラメーターを調整（必要に応じて）

3. **シグナルの確認**
   - 上向きの矢印（ライムグリーン）がエントリーシグナル
   - 赤い破線がストップロス推奨位置

4. **エントリー判断**
   - シグナルが表示されたら、追加の確認を行う
   - ストップロス位置を参考にリスク管理

## 検出ロジック詳細

### フェーズ1: 抵抗帯内での値動き
- 現在の1分足の終値が設定した抵抗帯の範囲内にあることを確認

### フェーズ2: 下落の勢いの衰え
以下のいずれかのパターンを検出：

1. **じわじわ下落/横ばいパターン**
   - 安値を更新しているが、値動きの角度が45度より緩やか
   - または、直近数本のローソク足の実体が非常に小さく価格が停滞

2. **ソーサー（お椀型）パターン**
   - 価格が下げ止まり、安値を切り上げる動き
   - 下落の勢いが弱まった形状

### フェーズ3: 強い反発（上昇への転換）
以下の3つの条件を全て満たす必要がある：

1. **大陽線の確定**
   - 直近1～2本の陽線が設定した閾値を大きく超える実体サイズ

2. **垂直に近い角度**
   - 反発を形成しているローソク足群が垂直に近い角度で上昇（60度以上）

3. **ヒゲの少なさ**
   - 上ヒゲをほとんど伴わず、一方的に上昇
   - 値動きに迷いがないことの証拠
