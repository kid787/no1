# ゴールド（XAUUSD）ロング専用EA v2.0

## 概要
2本のローソク足パターンを使用したゴールド専用の押し目買い戦略EA

**バージョン 2.0の新機能:**
- 複数時間足対応（15分足 & 1時間足）
- 1時間足レジスタンスゾーン検出機能
- レジスタンスゾーンでの自動利確

## ファイル構成
- `GoldLongEA.mq5` - メインEAファイル
- `EA_STRATEGY_PROMPT.md` - 戦略の詳細仕様書

## 戦略の特徴

### エントリー条件（ロングのみ）

#### 時間足設定
- **監視時間足**: M15（15分足）とH1（1時間足）
- **エントリー判定**: デフォルトでは両方の時間足でシグナル確認が必要
- パラメータ `RequireBothTimeframes` で変更可能

#### パターン検出条件
1. **ローソク足パターン**
   - 1本目：陰線
   - 2本目：陽線

2. **安値の確認**
   - 2本目の安値（Low）が1本目より明確に下にある
   - デフォルト：80ポイント（0.8ドル）以上の差

3. **実体サイズ**
   - 両方のローソク足が一定以上の実体サイズを持つ
   - デフォルト：30ポイント（0.3ドル）以上

4. **勝率フィルター（オプション）**
   - 2本目の高値が1本目より低い
   - 2本目の上ひげが短い（デフォルト：50ポイント以下）

### 決済条件

#### 利確（レジスタンスゾーン - 最優先）
- **レジスタンスゾーン検出**: 1時間足の過去100本分の高値を分析
- **判定条件**: 同じ価格帯（±50ポイント）に3回以上タッチ
- **利確条件**:
  - 現在価格がレジスタンスゾーン（±20ポイント以内）に到達
  - かつ、利益が出ている状態
  - 条件を満たせば即座に決済

#### 利確（条件付き - 補助）
- 利益が出ている状態で陰線の実体が完成したら決済
- 損失状態では陰線が出ても決済しない
- レジスタンスゾーン利確が優先

#### 損切り
- エントリーした2本目の安値から35ドル（350ポイント）下に固定

## パラメータ設定

### 基本設定
- **LotSize**: ロットサイズ（デフォルト：0.01）
- **MagicNumber**: マジックナンバー（デフォルト：234567）
- **TradeComment**: コメント（デフォルト：GoldLongEA_v2）

### エントリー条件
- **MinWickDifference_Points**: 安値の最小差（デフォルト：80ポイント）
- **MinBodySize_Points**: 最小実体サイズ（デフォルト：30ポイント）
- **UseHighFilter**: 勝率フィルター使用（デフォルト：true）
- **MaxUpperWick_Points**: 2本目の最大上ひげ（デフォルト：50ポイント）

### 決済条件
- **StopLoss_Points**: 損切り（デフォルト：350ポイント = 35ドル）
- **UseResistanceZone**: レジスタンスゾーン利確の使用（デフォルト：true）
- **ResistanceZoneLookback**: レジスタンス検出用の過去足数（デフォルト：100本）
- **ResistanceZoneRange_Points**: レジスタンスゾーン判定範囲（デフォルト：±50ポイント）
- **MinResistanceTouches**: レジスタンス判定の最小タッチ回数（デフォルト：3回）
- **ResistanceExitRange_Points**: レジスタンス到達判定範囲（デフォルト：±20ポイント）
- **UseConditionalTP**: 条件付き利確の使用・補助（デフォルト：true）

### トレード設定
- **MaxPositions**: 最大ポジション数（デフォルト：1）
- **EntryTimeframe1**: エントリー時間足1（デフォルト：M15 - 15分足）
- **EntryTimeframe2**: エントリー時間足2（デフォルト：H1 - 1時間足）
- **RequireBothTimeframes**: 両方の時間足でシグナル必要（デフォルト：true）
- **Slippage**: スリッページ（デフォルト：50ポイント）

## 使い方

1. **MT5へのインストール**
   ```
   MT5のデータフォルダ → MQL5 → Experts → GoldLongEA.mq5 をコピー
   ```

2. **コンパイル**
   - MetaEditorで GoldLongEA.mq5 を開く
   - F7キーでコンパイル

3. **チャートに適用**
   - XAUUSDのチャートを開く
   - 推奨時間足：M15（15分足）またはH1（1時間足）
   - ナビゲーターから GoldLongEA をチャートにドラッグ
   - **重要**: どちらの時間足でも動作しますが、両方の時間足データが必要です

4. **パラメータ調整**
   - 必要に応じてパラメータを調整
   - バックテストで最適化推奨

## 注意事項

1. **ゴールド専用**
   - このEAはXAUUSD（ゴールド）に最適化されています
   - 他の通貨ペアでは使用しないでください

2. **ポイント計算**
   - ゴールドは100ポイント = 1ドル
   - スプレッドは30〜50ポイント程度を想定

3. **リスク管理**
   - 必ず少額ロットでテストしてください
   - バックテストで戦略を検証してから実運用してください

4. **推奨環境**
   - 時間足：H1またはH4
   - VPS使用推奨（24時間稼働）
   - 低スプレッドのブローカー推奨

## バックテスト推奨設定

- **通貨ペア**: XAUUSD
- **時間足**: M15（15分足）または H1（1時間足）
- **期間**: 最低1年間
- **モデル**: 全ティック（可能な限り）
- **スプレッド**: 現在値または固定30〜50ポイント
- **最適化パラメータ**:
  - MinWickDifference_Points（50〜120）
  - MinBodySize_Points（20〜50）
  - ResistanceZoneLookback（50〜150）
  - MinResistanceTouches（2〜5）
