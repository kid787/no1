# XAUUSD Fintokei Scalper EA v2.2

XAUUSD（金/ドル）専用のMT5自動売買システム（Expert Advisor）です。Fintokeiプロップトレードチャレンジの厳格なリスク管理ルールを完全遵守しながら、高度なテクニカル分析に基づいたスキャルピング/デイトレードを行います。

## 🆕 v2.2の改善（最新）

## 📊 v2.1の新機能

### 高度なフィルター機能
- **ATRボラティリティフィルター**: 異常なボラティリティ時のエントリーを回避
  - XAUUSD最適範囲: 3.0-15.0 ATR
  - 高すぎる（15超）: リスクが大きすぎる
  - 低すぎる（3未満）: 利益機会が少ない

- **リスク/リワード比チェック**: 最小RR比 1:1.5を強制
  - 不利なトレードを事前に拒否
  - 質の高いトレードのみ実行

- **1トレード最大損失制限**: 証拠金の最大2%までに制限
  - 巨額損失の防止
  - より安全なリスク管理

- **トレーリングストップ機能**: 利益を自動追従
  - 200pips利益後に自動でSLを追従
  - 50pipsステップで調整
  - 利益を守りながら伸ばす

### 📊 高度なテクニカル分析

#### 1. グランビルの法則（Granville's Law）
- **200SMA**: 長期トレンド判定
- **100EMA**: 中期トレンドとエントリーポイント
- 8つのシグナルパターンを自動検出
  - 買い1-4: MA転換、押し目買い、乖離からの反発
  - 売り1-4: MA転換、戻り売り、乖離からの反落

#### 2. プライスアクション分析
- **つつみ足** (Engulfing): 強力な反転シグナル
- **ピンバー** (Pin Bar): 反発・反落を示唆
- **インサイドバー**: レンジ相場の識別
- **同時線** (Doji): 迷いと転換点

#### 3. 水平線（サポート/レジスタンス）
- 直近100本のローソク足から自動検出
- スイングハイ/ローの識別
- 価格の反発ポイントを予測

#### 4. デイリーピボット
- 前日の高値・安値・終値から自動計算
- R1, R2（レジスタンス）
- S1, S2（サポート）
- ピボットポイント

### 💰 高度な資金管理

#### ダイナミックロット計算
- 損切り幅に応じた最適ロットサイズ
- Fintokei制限（1日、全体、ポジション）を考慮
- エントリーポイントを損切りラインに近づけて高ロット化

#### 複数の制限の統合
```
実際のロット = min(
  1日の残り損失許容額に基づくロット,
  全体の残り損失許容額に基づくロット,
  ポジションリスク制限に基づくロット
)
```

### 🎯 洗練されたエグジット戦略

#### 1. 建値決済（Breakeven）

#### 4. 利確ターゲット

## トレードロジック

### エントリー条件
**最低2つ以上**のシグナルが同時に発生したときにエントリー

#### 買いシグナル例
1. グランビル買い2（100EMA引き付け）
2. 強気のピンバー発生
3. サポートライン近辺
→ **3つのシグナル** → 買いエントリー

#### 売りシグナル例
1. グランビル売り1（200SMA下抜け）
2. 弱気のつつみ足
→ **2つのシグナル** → 売りエントリー

```
エントリー

  ↓ YES

  ↓

```

## XAUUSDの特性

### ピップ計算
- XAUUSD: 1pip = 0.1ドル
- 100pips = 10ドル
- 例: 2000.00 → 2010.00 = 100pips

### ボラティリティ
- 1日の変動: 通常200-500pips（20-50ドル）
- 重要経済指標時: 1000pips以上（100ドル以上）の変動も

### 取引時間
- **最適な時間帯**:
  - ロンドン時間（16:00-19:00 JST）
  - ニューヨーク時間（22:00-02:00 JST）
- **避けるべき時間**:
  - 東京時間の早朝（動きが少ない）
  - 週末前（流動性低下）

## リスク管理のポイント

### Fintokeiチャレンジでの注意点

1. **毎日UTC 0時（日本時間9時）が基準**
   - この時刻の有効証拠金が1日の基準値になる
   - 朝9時前後は新規エントリーを避ける

2. **含み損も損失にカウント**
   - ポジション保有中は常に有効証拠金を監視
   - 含み損が大きい場合は新規エントリー不可

3. **段階的な利益確保**
   - 分割決済により確実に利益を積み上げる
   - 建値移動により損失リスクをゼロ化

4. **取引の再現性**
   - 一貫したルールベースのトレード
   - ランダムなトレードは避ける
   - このEAは明確なルールに基づく

## トラブルシューティング

### エントリーされない
- シグナル数が MinSignalsRequired 未満（v2.1は2つ必要）
- 既にMaxPositions数のポジションを保有
- Fintokeiリスク制限に到達している
- **v2.0新規**: 時間帯フィルターで制限されている（v2.2: デフォルトOFF）
- **v2.0新規**: 金曜日または月曜日の取引が制限されている
- **v2.0新規**: 1日の最大トレード数に到達（v2.1: 10回）
- **v2.0新規**: 連続負けトレード後の休止中
- **v2.1新規**: ATRが範囲外（v2.2: デフォルトOFF）
- **v2.1新規**: RR比が不十分（v2.2: デフォルトOFF、0=チェックスキップ）
- **v2.1新規**: 1トレード最大損失（2%）超過
- ログを確認: ShowDebugInfo = true に設定

### バックテストでトレードが0件
**v2.2で解決済み** - デフォルト設定で基本性能を確認可能
- v2.1ではフィルターが厳しすぎた（RR比、ATR、時間帯）
- v2.2ではフィルターをデフォルトOFFに設定
- 必要に応じてフィルターを段階的にON

### トレードが多すぎる / 少なすぎる
- **v2.1**: `MaxTradesPerDay`で調整（デフォルト10回）
- シグナル数を調整: `MinSignalsRequired`を増やすと厳格に
- 時間帯を狭める: `TradingStartHour`, `TradingEndHour`（v2.1: 5-18時）
- **v2.1新規**: ATRフィルターを調整: `MinATR`, `MaxATR`

### 連続負けで停止してしまう
- **v2.0**: `MaxConsecutiveLosses`を増やす（デフォルト3回）
- ただし、リスク管理のため5回以下を推奨
- `PauseAfterLoss_Minutes`で休止時間を調整

### 損切りが浅すぎる
- SLBufferPercent を増やす（v2.0デフォルト5.0%）
- 例: 7.0%に変更すると損切りラインに更に余裕

### 利確が早すぎる
- PartialClose1_Pips, PartialClose2_Pips を増やす
- 例: 200 → 300, 400 → 600

### ロットが小さすぎる
- RiskPercentPerTrade を増やす（デフォルト2.0%）
- ただし、Fintokeiルールの範囲内で調整
