# XAUUSD Non-Entry Zone Detector

MT5用のXAUUSD向けインジケーター - 上位足のハラミ足パターンに基づいて非エントリーゾーンを識別します。

## 概要

このインジケーターは、XAUUSDチャート上に上位足のハラミ足（インサイドバー）によって定義される「レンジ/膠着ゾーン」を視覚的に表示します。このゾーン内はボラティリティが収縮しており、ブレイクアウト戦略以外では取引に不向きなエリアです。

## 主要機能

### 1. 上位足ハラミ足検出
- 指定した上位時間足（デフォルト: 4時間足）でハラミ足パターンを自動検出
- 親足が子足を完全に包み込むインサイドバーパターンを識別

### 2. 非エントリーゾーン描画
- 検出されたハラミ足の高値・安値範囲を背景色で視覚化
- 現在時刻まで自動延長表示
- 高値・安値ラインを点線で表示（ブレイクアウトポイントの明確化）

### 3. 低ボラティリティフィルター
- レンジ幅が設定値（デフォルト: 20 pips）未満のゾーンを特別表示
- 低ボラティリティゾーンには警告ラベルとカラー変更で注意喚起

### 4. トレンド中盤アラート（オプション）
- トレンド中盤で発生する包み足パターン（信頼性の低いサイン）を検出
- チャート上に "MID-RANGE ALERT" テキストを表示

### 5. ブレイクアウトアラート
- ゾーンの高値・安値を終値でブレイクした際に自動アラート
- ブレイクアウト方向を示すメッセージを表示

## インストール方法

1. `XAUUSD_NoEntry_Zone_Detector.mq5` をMT5の `MQL5/Indicators` フォルダにコピー
2. MT5を再起動、またはナビゲーターウィンドウで更新
3. チャートにインジケーターをドラッグ&ドロップ

## パラメータ設定

| パラメータ名 | 型 | デフォルト値 | 説明 |
|-------------|-----|------------|------|
| Harami_Timeframe | ENUM_TIMEFRAMES | PERIOD_H4 | ハラミ足を検出する上位時間足 |
| Range_Pips_Min | int | 20 | 低ボラティリティと判定する最小レンジ幅（pips） |
| Zone_Color | color | clrDimGray | 通常の非エントリーゾーン背景色 |
| Zone_Opacity | int | 50 | 通常ゾーンの透明度 (0-255) |
| Enable_MidRange_Alert | bool | false | トレンド中盤の包み足警告を有効化 |
| MidRange_Period | int | 20 | 中盤判定用の期間 |
| Alert_Breakout | bool | true | ゾーンブレイクアウト時のアラートを有効化 |
| LowVol_Zone_Color | color | clrYellow | 低ボラティリティゾーンの色 |
| LowVol_Zone_Opacity | int | 80 | 低ボラティリティゾーンの透明度 |

## 使い方

### 基本的な使用方法

1. XAUUSDチャートを開く
2. インジケーターを適用
3. 上位足で検出されたハラミ足の範囲が背景色で表示される
4. 表示されたゾーン内での新規エントリーを避ける
5. ゾーンブレイク時はトレンドフォロー戦略のチャンス

### 推奨設定

- **スキャルピング/デイトレード**: Harami_Timeframe = PERIOD_H4
- **スイングトレード**: Harami_Timeframe = PERIOD_D1
- **ボラティリティが高い時期**: Range_Pips_Min = 30-40
- **ボラティリティが低い時期**: Range_Pips_Min = 15-20

## トレード戦略への応用

### エントリー回避
- 黄色（低ボラティリティ）ゾーン内でのエントリーは特に避ける
- 灰色ゾーン内は「損小利小」になりやすい

### ブレイクアウト戦略
- ゾーン上限/下限のブレイク確定時はエントリーチャンス
- アラート機能でタイミングを逃さない
- ブレイク方向へのトレンドフォロー

### リスク管理
- 中盤アラートが表示された包み足は信頼性が低いため慎重に
- ゾーン内でのレンジトレードはリスクリワード比が悪化

## 技術仕様

- **開発言語**: MQL5
- **対応プラットフォーム**: MetaTrader 5
