# Granville Gold Trading System

XAU/USD（ゴールド）向けのグランビルの法則ベースの自動売買システム（MT5用EA + インジケーター）

## 📋 概要

このシステムは、グランビルの法則（8つのルール）に基づいたトレンドフォロー戦略を実装したMT5用の自動売買システムです。プロップトレーディングファームの要件に対応した厳格なリスク管理機能を備えています。

### 主な特徴

- ✅ グランビルの法則（Rule 1-3, 5-7）による高精度なエントリーシグナル
- ✅ マルチタイムフレーム分析（H4でトレンド確認、M30でエントリー）
- ✅ 7層のフィルターシステムで精度向上
- ✅ プロップトレード対応（デイリー損失リミット機能）
- ✅ 部分利確とブレイクイーブン機能
- ✅ 最適化済みパラメータ（2025年通年バックテスト済み）

## 🚀 インストール

### 1. ファイルのコピー

MT5のデータフォルダに以下のファイルをコピーします：

```
MQL5/
├── Experts/
│   └── GranvilleEA.mq5
└── Indicators/
    └── GranvilleMA.mq5
```

MT5のデータフォルダは、MT5メニューの「ファイル」→「データフォルダを開く」から確認できます。

### 2. コンパイル

1. MT5のMetaEditorを開く
2. `GranvilleEA.mq5` を開いてコンパイル（F7キー）
3. `GranvilleMA.mq5` を開いてコンパイル（F7キー）
4. エラーがないことを確認

### 3. チャート設定

1. XAU/USDのチャートを開く
2. 時間足をM30に設定
3. インジケーター `GranvilleMA` をチャートに追加
4. EA `GranvilleEA` をチャートにアタッチ
5. 自動売買を有効にする

## 🎯 戦略詳細

### グランビルの法則

システムは以下のグランビルの法則を実装しています：

**買いシグナル（Rule 1-3）**
- **Rule 1**: MA上向き + 価格がMAを上抜け（新トレンド開始）
- **Rule 2**: MA上向き + 価格がMAを一時下抜け後に回復（ダマシからの回復）
- **Rule 3**: MA上向き + 価格がMAに接近して反発（押し目買い）

**売りシグナル（Rule 5-7）**
- **Rule 5**: MA下向き + 価格がMAを下抜け（新トレンド開始）
- **Rule 6**: MA下向き + 価格がMAを一時上抜け後に下落（ダマシからの回復）
- **Rule 7**: MA下向き + 価格がMAに接近して反落（戻り売り）

### 7層のフィルターシステム

エントリー前にすべての条件を満たす必要があります：

1. **MTFトレンドフィルター（H4）**: H4の75 EMAが20本前と比較して10 pips以上変化
2. **ローカルトレンドフィルター（M30）**: M30の75 EMAが3本連続で上昇/下降
3. **ADXトレンド強度フィルター**: ADX ≥ 20.0
4. **ATRボラティリティフィルター**: ATR倍率が0.5〜2.0の範囲内
5. **200 EMAフィルター**: 買いは価格 > 200 EMA、売りは価格 < 200 EMA
6. **MA近接度チェック**: 価格が75 EMAの100 pips以内
7. **時間帯フィルター**: 12:00〜05:00（17時間、NY/アジアセッション）

## 🛡️ リスク管理機能

### ポジションサイジング

- 口座残高の2%をリスクとして設定
- SL距離に基づいて自動計算
- 最大ロット数制限あり

### ストップロスとテイクプロフィット

- **SL**: スイングハイ/ローの外側（見つからない場合はエントリー価格の±2%）
- **TP**: SL距離 × 2.0（リスクリワード比率2:1）

### 部分利確

- TP距離の50%到達時に発動
- ポジションの50%を決済
- 残り50%はフルTPまで保持

### ブレイクイーブン

- SL幅の50%の利益が出た時に発動
- SLをエントリー価格 + 10 pipsに移動

### デイリー損失リミット（プロップトレード対応）

- 当日の損失が開始残高の4%を超えたら取引停止
- 日付が変わると自動リセット
- プロップファームの規則に準拠

## 🔧 トラブルシューティング

### EAが取引しない場合

1. **自動売買が有効か確認**: チャート右上の「自動売買」ボタンが緑色になっているか
2. **時間帯フィルター**: 現在の時刻が取引時間内か（デフォルト12:00-05:00）
3. **フィルター条件**: インジケーターのステータスラベルで各フィルターの状態を確認
4. **デイリー損失リミット**: 当日の損失が4%に達していないか
5. **ログ確認**: エキスパートログでエラーメッセージを確認

### 「Unsupported filling mode」エラーが出る場合

**v1.10で修正済み**: 最新版では自動的にブローカーがサポートするFilling Modeを検出します。

- エキスパートログで「Filling Mode: FOK / IOC / RETURN」と表示されることを確認
- 古いバージョンを使用している場合は、最新版に更新してください

### デバッグログの確認方法

v1.10以降では、以下のデバッグ情報がログに出力されます：

- フィルターブロック理由（1時間ごと）
- MTFトレンド状態
- ADX/ATR値
- 注文実行の詳細

ログは「ツールボックス」→「エキスパート」タブで確認できます。

### インジケーターが表示されない場合

1. コンパイルエラーがないか確認
2. チャートの時間足がM30になっているか確認
3. インジケーターを削除して再度追加

### シグナルが多すぎる/少なすぎる場合

- **多すぎる場合**: ADX_Min_Levelを上げる（例：25.0）、MA_Proximity_Pipsを下げる（例：50）
- **少なすぎる場合**: ADX_Min_Levelを下げる（例：15.0）、MA_Proximity_Pipsを上げる（例：150）
