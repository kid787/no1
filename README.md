# XAUUSD Fintokei Scalper EA

XAUUSD（金/ドル）専用のMT5自動売買システム（Expert Advisor）です。Fintokeiプロップトレードチャレンジの厳格なリスク管理ルールを完全遵守しながら、高度なテクニカル分析に基づいたスキャルピング/デイトレードを行います。

## 主な特徴

### ✅ Fintokeiルール完全対応
- **1日の損失制限**: 資金の4.9%まで（5%未満）
- **全体の損失制限**: 初期資金の9.9%まで（10%未満）
- **ポジションリスク**: 1ポジションあたり最大3%
- **UTC 0時リセット**: 毎日の損失計算を自動リセット
- **リアルタイム監視**: 含み損を含めた有効証拠金を常時監視
- **自動ストップ**: リスク制限到達時は自動的に取引停止

### 📊 高度なテクニカル分析

#### 1. グランビルの法則（Granville's Law）
- **200SMA**: 長期トレンド判定
- **100EMA**: 中期トレンドとエントリーポイント
- 8つのシグナルパターンを自動検出
  - 買い1-4: MA転換、押し目買い、乖離からの反発
  - 売り1-4: MA転換、戻り売り、乖離からの反落

#### 2. プライスアクション分析
- **つつみ足** (Engulfing): 強力な反転シグナル
- **ピンバー** (Pin Bar): 反発・反落を示唆
- **インサイドバー**: レンジ相場の識別
- **同時線** (Doji): 迷いと転換点

#### 3. 水平線（サポート/レジスタンス）
- 直近100本のローソク足から自動検出
- スイングハイ/ローの識別
- 価格の反発ポイントを予測

#### 4. デイリーピボット
- 前日の高値・安値・終値から自動計算
- R1, R2（レジスタンス）
- S1, S2（サポート）
- ピボットポイント

### 💰 高度な資金管理

#### ダイナミックロット計算
- 損切り幅に応じた最適ロットサイズ
- Fintokei制限（1日、全体、ポジション）を考慮
- エントリーポイントを損切りラインに近づけて高ロット化

#### 複数の制限の統合
```
実際のロット = min(
  1日の残り損失許容額に基づくロット,
  全体の残り損失許容額に基づくロット,
  ポジションリスク制限に基づくロット
)
```

### 🎯 洗練されたエグジット戦略

#### 1. 建値決済（Breakeven）
- 含み益が150pips（デフォルト）に達したら建値+10pipsに損切り移動
- 損失リスクをゼロ化

#### 2. 分割利確（Partial Close）
- **第1ターゲット**: 200pips（+20ドル）で30%決済
- **第2ターゲット**: 400pips（+40ドル）で30%決済
- **第3ターゲット**: 600pips（+60ドル）で残り40%決済
- 利益を段階的に確保

#### 3. 損切り設定
- ダウ理論に基づく直近高値/安値を使用
- 騙し（false break）を考慮して3%の余裕
- 例: 買いの場合、直近安値 - 3%

#### 4. 利確ターゲット
- 直近高値/安値
- 上位足の重要レベル
- デイリーピボット
- 20SMA実体抜け

## インストール方法

### 1. MT5データフォルダを開く
MT5を起動 → ファイル → データフォルダを開く

### 2. ファイルを配置
```
MQL5/
├── Experts/
│   └── XAUUSD_Fintokei_Scalper.mq5
└── Include/
    ├── FintokeiRiskManager.mqh
    ├── TechnicalSignals.mqh
    └── TradeManager.mqh
```

### 3. コンパイル
- MetaEditorでXAUUSD_Fintokei_Scalper.mq5を開く
- F7キーを押してコンパイル
- エラーがないことを確認

### 4. チャートに適用
- XAUUSDの5分足チャートを開く
- ナビゲーターから「XAUUSD_Fintokei_Scalper」をドラッグ&ドロップ

- **通貨ペア**: XAUUSD専用

```

MaxPositionRiskPercent = 3.0 // ポジション最大リスク
```

## トレードロジック

### エントリー条件
**最低2つ以上**のシグナルが同時に発生したときにエントリー

#### 買いシグナル例
1. グランビル買い2（100EMA引き付け）
2. 強気のピンバー発生
3. サポートライン近辺
→ **3つのシグナル** → 買いエントリー

#### 売りシグナル例
1. グランビル売り1（200SMA下抜け）
2. 弱気のつつみ足
→ **2つのシグナル** → 売りエントリー

### エグジット判断フロー
```
エントリー
  ↓
含み益 +150pips?
  ↓ YES
建値+10pipsに損切り移動（リスクゼロ化）
  ↓
+200pips到達?
  ↓ YES
30%決済（利益確保）
  ↓
+400pips到達?
  ↓ YES
さらに30%決済（60%が既に利益確定）
  ↓
+600pips到達 or 20SMA実体抜け?
  ↓ YES
残り40%決済（完全クローズ）
```

## XAUUSDの特性

### ピップ計算
- XAUUSD: 1pip = 0.1ドル
- 100pips = 10ドル
- 例: 2000.00 → 2010.00 = 100pips

### ボラティリティ
- 1日の変動: 通常200-500pips（20-50ドル）
- 重要経済指標時: 1000pips以上（100ドル以上）の変動も

### 取引時間
- **最適な時間帯**:
  - ロンドン時間（16:00-19:00 JST）
  - ニューヨーク時間（22:00-02:00 JST）
- **避けるべき時間**:
  - 東京時間の早朝（動きが少ない）
  - 週末前（流動性低下）

## リスク管理のポイント

### Fintokeiチャレンジでの注意点

1. **毎日UTC 0時（日本時間9時）が基準**
   - この時刻の有効証拠金が1日の基準値になる
   - 朝9時前後は新規エントリーを避ける

2. **含み損も損失にカウント**
   - ポジション保有中は常に有効証拠金を監視
   - 含み損が大きい場合は新規エントリー不可

3. **段階的な利益確保**
   - 分割決済により確実に利益を積み上げる
   - 建値移動により損失リスクをゼロ化

4. **取引の再現性**
   - 一貫したルールベースのトレード
   - ランダムなトレードは避ける
   - このEAは明確なルールに基づく

## トラブルシューティング

### エントリーされない
- シグナル数が MinSignalsRequired 未満
- 既にMaxPositions数のポジションを保有
- Fintokeiリスク制限に到達している
- ログを確認: ShowDebugInfo = true に設定

### 損切りが浅すぎる
- SLBufferPercent を増やす（デフォルト3.0%）
- 例: 5.0%に変更すると損切りラインに余裕

### 利確が早すぎる
- PartialClose1_Pips, PartialClose2_Pips を増やす
- 例: 200 → 300, 400 → 600

### ロットが小さすぎる
- RiskPercentPerTrade を増やす（デフォルト2.0%）
- ただし、Fintokeiルールの範囲内で調整
