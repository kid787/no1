## 📋 概要

このインジケーターは、XAUUSD（金）の1分足チャートでデイトレードを行うトレーダー向けに開発されました。上位足の環境認識を自動化し、取引を避けるべき「ノーエントリーゾーン」を視覚的に表示することで、リスクの高い場面でのエントリーを防ぎます。

## ✨ 主要機能

### 機能A: 上位足の強力な抵抗帯/サポートゾーン
- 上位足（デフォルト：H1、H4）から強力なレジスタンス/サポートゾーンを自動検出
- スイングハイ/スイングローの価格クラスタリングにより、最も意識されている価格帯を特定
- 濃い赤色（レジスタンス）と濃い緑色（サポート）で視覚化

### 機能B: レンジ相場の中央揉み合いゾーン
- 上位足（デフォルト：H4）で形成されているレンジを自動検出
- レンジの中央40%（カスタマイズ可能）を「揉み合いゾーン」として特定
- 黄色の半透明ゾーンで表示し、取引を避けるべきエリアを明示

### 機能C: トレンド転換ライン（ネックライン）
- ダウ理論に基づく押し安値/戻り高値を自動検出
- トレンド構造が崩れる可能性のある重要ラインを破線で表示
- 価格接近時（デフォルト：10 Pips以内）に色がオレンジに変化して警告

## 🎨 視覚化仕様

| 要素 | 表示形式 | 色 | 説明 |
|------|---------|-----|------|
| HTFレジスタンスゾーン | 網掛け | 濃い赤色（半透明） | 強い売り圧力が予想される価格帯 |
| HTFサポートゾーン | 網掛け | 濃い緑色（半透明） | 強い買い圧力が予想される価格帯 |
| レンジ中央ゾーン | 網掛け | 黄色（半透明） | 値動きが不安定な揉み合いエリア |
| ネックライン | 破線 | 青色→オレンジ（接近時） | トレンド構造の境界線 |

## 🚀 インストール方法

### 1. MT5へのインストール

1. `Indicators/MTF_NoEntry_Zone.mq5` ファイルをダウンロード
2. MT5を開き、**ファイル → データフォルダを開く** をクリック
3. **MQL5 → Indicators** フォルダに `MTF_NoEntry_Zone.mq5` をコピー
4. MT5のナビゲーターウィンドウで右クリック → **更新** を選択
5. ナビゲーターの「インジケーター」カテゴリに「MTF_NoEntry_Zone」が表示されます

### 2. チャートへの適用

1. 1分足チャート（M1）を開く
2. ナビゲーターから「MTF_NoEntry_Zone」をチャートにドラッグ&ドロップ
3. パラメータ設定ウィンドウが表示されます（必要に応じて調整）
4. **OK**をクリックして適用

## ⚙️ パラメータ設定

### 上位足レジスタンス/サポートゾーン設定
| パラメータ | デフォルト値 | 説明 |
|-----------|------------|------|
| HTF1_Timeframe | H1 | 上位足1の時間軸 |
| HTF2_Timeframe | H4 | 上位足2の時間軸 |
| HTF_Lookback_Bars | 100 | 抵抗帯を特定するために遡るバー数 |
| HTF_Zone_Pips | 5.0 | ゾーンの幅（Pips） |
| HTF_Resistance_Color | 濃い赤色 | レジスタンスゾーンの色 |
| HTF_Support_Color | 濃い緑色 | サポートゾーンの色 |
| HTF_Zone_Transparency | 220 | ゾーンの透明度（0-255） |

### レンジ中央ゾーン設定
| パラメータ | デフォルト値 | 説明 |
|-----------|------------|------|
| Range_Timeframe | H4 | レンジ計算用の時間軸 |
| Range_Center_Percentage | 0.4 | 中央ゾーンの割合（0.4=40%） |
| Range_Center_Color | 黄色 | レンジ中央ゾーンの色 |
| Range_Zone_Transparency | 230 | ゾーンの透明度（0-255） |

### ネックライン設定
| パラメータ | デフォルト値 | 説明 |
|-----------|------------|------|
| Neckline_Timeframe | H4 | ネックライン計算用の時間軸 |
| Neckline_Color | 青色 | ネックラインの色 |
| Neckline_Alert_Color | オレンジ色 | 価格接近時の警告色 |
| Neckline_Alert_Pips | 10.0 | 警告を発する距離（Pips） |
| Neckline_Width | 2 | ラインの太さ |
| Neckline_Style | 破線 | ラインのスタイル |

### 一般設定
| パラメータ | デフォルト値 | 説明 |
|-----------|------------|------|
| Show_HTF_Zones | true | 上位足ゾーンを表示 |
| Show_Range_Zone | true | レンジ中央ゾーンを表示 |
| Show_Neckline | true | ネックラインを表示 |
| Max_Zones_Display | 5 | 最大表示ゾーン数 |

## 📖 使用方法

### 基本的な使い方

1. **ノーエントリーゾーンの確認**
   - 価格がレジスタンス/サポートゾーン内にある場合 → エントリーを見送る
   - 価格がレンジ中央ゾーン内にある場合 → 揉み合いの可能性が高いため様子見
   - ネックラインがオレンジ色に変化した場合 → トレンド転換の可能性に注意

2. **エントリータイミング**
   - ゾーンを明確にブレイクした後のリテストでエントリー
   - レンジの上限/下限付近（中央ゾーン外）でエントリー
   - ネックラインのブレイク後、トレンドフォローでエントリー

3. **リスク管理**
   - ノーエントリーゾーン内ではポジションを持たない
   - ゾーン境界をストップロスの目安にする
   - 複数のゾーンが重なる箇所は特に注意

## 🔧 技術仕様

- **対応プラットフォーム**: MetaTrader 5
- **プログラミング言語**: MQL5
- **推奨チャート**: 1分足（M1）
- **推奨通貨ペア**: XAUUSD（Gold）
- **計算方式**:
  - スイングポイント検出（前後2本のバー比較）
  - 価格クラスタリング（類似価格帯のグループ化）
  - トレンド判定（直近の高値・安値の推移）
