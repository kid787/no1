# MT5 Expert Advisor Collection

MT5用のエキスパートアドバイザー（EA）とインジケーターのコレクション

## 🌟 Granville EA Enhanced v2.1 (最新版)

### 概要

Granville EA Enhanced v2.1は、グランビルの法則に基づいたトレンドフォロー型のエキスパートアドバイザーです。LotCalculator.mq5の高精度なロット計算方法を統合し、さらに増し玉（ピラミッディング）機能を実装。**v2.1ではプロフィットファクター向上のための最適化**を実施しました。

**バックテスト結果（期待値）:**
- プロフィットファクター: 1.25 → **1.5～1.8** 目標
- 最大ドローダウン: 34% → **15～20%** 目標
- 平均負けトレード: -30,064円 → **-15,000円** 目標

### 主な機能

#### 1. 高精度なロット計算

- **LotCalculator.mq5のロジックを統合**
  - `GetPipSize()`: 通貨ペアに応じた正確なPipサイズ計算（3/5桁対応）
  - `CalculateLossPerLot()`: ティックサイズとティックバリューを使用した精密な損失計算
  - `NormalizeLotSize()`: ブローカーの制約に合わせたロット正規化

- **厳密なリスク管理**
  - 各ポジションで口座残高の2%のリスク（設定可能）
  - 損切りラインまでの含み損が指定した資金量の％になるようにロット自動調整

#### 2. 増し玉（ピラミッディング）機能

含み益が出ているポジションに対して、同じ方向に追加エントリーを行います。

**追加エントリーの条件:**
- 既存ポジションの含み益が一定水準以上（デフォルト: リスクの50%）
- 最後のエントリーから一定距離離れている（デフォルト: 50 pips）
- トレンドが継続している（同じエントリーシグナルが発生）
- 最大ポジション数に達していない（デフォルト: 3）
- 全て同じ方向のポジションのみ（反対方向のポジションがある場合は追加しない）

**各追加ポジションも同じリスク管理:**
- 各ポジションで独立して口座残高の2%リスク
- 新しいスイングポイントに基づく損切り設定
- リスクリワード比率2:1の利確設定

#### 3. グランビルの法則に基づくエントリー

**買いシグナル（3つのルール）:**
- ルール1: MA上抜けブレイクアウト（新トレンド開始）
- ルール2: MAリバーサル回復（フォールスブレイクからの回復）
- ルール3: プルバック買い（既存トレンドでの押し目買い）

**売りシグナル（3つのルール）:**
- ルール5: MA下抜けブレイクアウト（新トレンド開始）
- ルール6: MAリバーサル回復（フォールスブレイクからの回復）
- ルール7: プルバック売り（既存トレンドでの戻り売り）

#### 4. トレンド分析

- **マルチタイムフレーム（MTF）確認**: H4足でのトレンド方向確認
- **ADXフィルター**: トレンド強度の最低閾値（デフォルト: 20）
- **200EMAフィルター**: 長期トレンドとの整合性確認

#### 5. リスク管理機能

- **ブレークイーブン**: 含み益が一定水準に達したら損切りをエントリー価格に移動
- **部分利確**: 利確目標の一定割合に達したらポジションの一部を決済
- **日次損失制限**: 1日の損失が設定値を超えたら新規取引を停止
- **時間フィルター**: 指定した時間帯のみ取引
- **ボラティリティフィルター**: ATR倍率による適切なボラティリティ範囲のみ取引

### インストール方法

1. MT5のデータフォルダを開く（ファイル → データフォルダを開く）
2. `MQL5/Experts/` フォルダに `GranvilleEA_Enhanced.mq5` をコピー
3. MetaEditorでコンパイル（F7キー）
4. MT5のナビゲーターウィンドウからチャートにドラッグ&ドロップ
