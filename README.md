# MT5 ロット計算ユーティリティ

## 概要

MT5（MetaTrader 5）上で動作するロット計算インジケーターです。
指定した損切り幅とリスク許容度（口座残高の1%または2%）に基づいて、最適なロットサイズを自動計算し、チャート上に表示します。

## 目的

このツールは、トレーダーが適切な資金管理を実践するために設計されています。
特に以下の場合に有用です：

- **ボラティリティに応じた損切り幅**: ATRなどを使用した可変的な損切り設定
- **チャート根拠に基づく損切り**: 直近安値/高値などの重要ポイントまでの距離
- **リスク管理の徹底**: 常に口座残高の一定割合（1%または2%）以内にリスクを固定

## 主な機能

✓ 口座残高に基づいた許容損失額の自動計算
✓ 損切り幅（Pips）に応じた最適ロットサイズの算出
✓ ブローカーの制約（最小/最大/ステップサイズ）への自動対応
✓ クロス円・非クロス円ペアの両方に対応
✓ リアルタイムでチャート上に結果を表示

## インストール方法

1. `LotCalculator.mq5` ファイルをMT5のインジケーターフォルダにコピーします：
   ```
   C:\Users\[ユーザー名]\AppData\Roaming\MetaQuotes\Terminal\[インスタンスID]\MQL5\Indicators\
   ```

2. MT5を起動し、メタエディター（MetaEditor）を開きます

3. `LotCalculator.mq5` をコンパイルします（F7キー）

4. チャートにインジケーターをドラッグ&ドロップするか、「挿入」→「インジケーター」→「カスタム」→「LotCalculator」から追加します

## パラメータ設定

### 入力パラメータ

| パラメータ名 | 変数名 | デフォルト値 | 説明 |
|------------|--------|------------|------|
| リスク許容度 (%) | RiskPercent | 2.0 | 1回のトレードで許容する最大損失の口座残高に対する割合（例: 1.0 = 1%, 2.0 = 2%） |
| 損切り幅 (Pips) | SL_Pips_Input | 30.0 | 損切りラインまでの価格差をPips単位で指定 |
| 表示桁数 | LotDigits | 2 | 計算されたロットサイズの小数点以下の表示桁数 |

### パラメータ変更方法

1. チャート上でインジケーターを右クリック
2. 「LotCalculator」→「プロパティ」を選択
3. 「パラメーターの入力」タブで値を変更
4. 「OK」をクリック

## 表示内容

チャート左上に以下の情報が表示されます：

```
[ロット計算結果]
許容リスク: 2.0% (最大損失: 20000.00 JPY)
SL幅: 30.0 Pips
推奨ロット数: 0.66 Lot
───────────────────
口座残高: 1000000.00 JPY
1ロットあたり損失: 30000.00 JPY
```

## 計算ロジック

### ステップ A: 許容損失額の決定

```
許容損失額 = 口座残高 × (RiskPercent / 100)
```

例: 口座残高が100万円、リスク許容度が2%の場合
```
許容損失額 = 1,000,000 × 0.02 = 20,000円
```

### ステップ B: 1ロットあたりの損失額の計算

現在の通貨ペア、損切り幅（Pips）、およびブローカーの取引条件を考慮し、
1ロット（100,000通貨単位）で取引した場合の損失額を計算します。

MQL5の `SymbolInfoDouble` 関数を使用して：
- `SYMBOL_TRADE_TICK_SIZE`: ティックサイズ
- `SYMBOL_TRADE_TICK_VALUE`: ティック値（口座通貨建て）
- `SYMBOL_POINT`: 最小価格変動単位

これらの値から、正確な1ロットあたりの損失額（円換算）を算出します。

### ステップ C: 適正ロット数の決定

```
適正ロット数 = 許容損失額 / 1ロットあたりの損失額
```

例: 許容損失額が20,000円、1ロットあたりの損失額が30,000円の場合
```
適正ロット数 = 20,000 / 30,000 = 0.66ロット
```

### ステップ D: ロットサイズ調整

計算結果を以下の制約に合わせて調整します：
- `SYMBOL_VOLUME_MIN`: ブローカーの最小ロットサイズ
- `SYMBOL_VOLUME_MAX`: ブローカーの最大ロットサイズ
- `SYMBOL_VOLUME_STEP`: ロットステップ（増減単位）

## 使用例

### 例1: 保守的なトレード（リスク1%）

- 口座残高: 100万円
- リスク許容度: 1%
- 損切り幅: 20 Pips

→ 推奨ロット数: 約0.50ロット（損失額10,000円以内）

### 例2: 標準的なトレード（リスク2%）

- 口座残高: 50万円
- リスク許容度: 2%
- 損切り幅: 40 Pips

→ 推奨ロット数: 約0.25ロット（損失額10,000円以内）

### 例3: ボラティリティの高い相場（広い損切り）

- 口座残高: 200万円
- リスク許容度: 2%
- 損切り幅: 100 Pips

→ 推奨ロット数: 約0.40ロット（損失額40,000円以内）

## 注意事項

1. **リアルタイム更新**: インジケーターは新しいバーの開始時、またはパラメータ変更時に再計算されます

2. **クロス円以外の通貨ペア**: EUR/USDなどの非円建てペアでも、自動的に口座通貨（JPY）に換算して計算します

3. **ブローカーによる違い**: 最小ロット、最大ロット、ロットステップはブローカーにより異なります。本インジケーターは自動的にこれらの制約に対応します

4. **資金管理の重要性**: このツールは適切なロットサイズを提案しますが、最終的な判断はトレーダー自身が行ってください

## トラブルシューティング

### 表示が更新されない場合

- チャートを右クリック→「更新」を選択
- インジケーターを一度削除して再度追加

### ロット数が0.00と表示される場合

- 口座残高が少なすぎる、または損切り幅が広すぎる可能性があります
- リスク許容度を上げるか、損切り幅を狭くしてください

### 計算結果が正しくない場合

- ブローカーのシンボル設定を確認してください
- デモ口座で動作テストを行ってください
