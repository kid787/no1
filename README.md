# HighWinRate Entry Filter - 高勝率エントリーフィルター

MQL4インジケーター：複数時間軸分析と市場心理に基づく高勝率エントリーフィルター

## 概要

このインジケーターは、「ゴールデンルール」と「守破離」の概念を実装し、トレーダーが優位性の高いエントリーポイントを見つけるための視覚的フィルターとして機能します。

### バージョン

- **通常版（FX通貨ペア用）**: `HighWinRate_Entry_Filter.mq4`
- **XAUUSD専用版（ゴールド用）**: `HighWinRate_Entry_Filter_XAUUSD.mq4` ⭐NEW

**XAUUSD（金/ゴールド）をトレードする場合は、XAUUSD専用版の使用を強く推奨します。**
金特有のボラティリティと価格特性に最適化されており、デイリーピボット自動表示、ロンドン・ニューヨーク両セッション対応など、金トレーダーに必要な機能が搭載されています。

詳細は [XAUUSD専用ガイド](XAUUSD_GUIDE.md) をご覧ください。

### 主な特徴

1. **マルチタイムフレーム（MTF）分析**
   - 上位足（King）と基準足（Base）のトレンド方向を自動判定
   - 両時間足のトレンドが一致した「秩序」のある状態を検出

2. **時間帯フィルター**
   - ロンドンセッションのハイライト表示
   - ボラティリティの高い時間帯でのトレードを促進

3. **サポート/レジスタンス自動検出**
   - 上位足の主要なS/Rラインを自動描画
   - 「相場の支配者」のラインを可視化

4. **クラスター検出**
   - 価格の揉み合いゾーン（クラスター/ブロック）を自動検出
   - ボックスとして描画し、ブレイクアウトを視覚化

5. **エントリーシグナル**
   - 優位性の高い条件が揃った際にアラート
   - サウンド＆ポップアップ通知

## インストール方法

### MetaTrader 4へのインストール

1. **ファイルのコピー**
   ```
   Indicators/HighWinRate_Entry_Filter.mq4
   ```
   を MetaTrader 4 の以下のフォルダにコピー：
   ```
   [MT4インストールフォルダ]/MQL4/Indicators/
   ```

2. **コンパイル**
   - MetaTrader 4を起動
   - メニューから「ファイル」→「データフォルダを開く」
   - `MQL4/Indicators/` フォルダに移動
   - MetaEditor を開き、`HighWinRate_Entry_Filter.mq4` を開く
   - F7キーまたは「コンパイル」ボタンでコンパイル

3. **チャートに適用**
   - ナビゲーターウィンドウの「インジケータ」内から「HighWinRate_Entry_Filter」を探す
   - チャートにドラッグ&ドロップ

## パラメーター設定

### 時間足設定

| パラメーター | デフォルト | 説明 |
|------------|----------|------|
| King_TimeFrame | D1（日足） | 最上位足 - 相場の支配者 |
| Base_TimeFrame | H1（1時間足） | 基準足 - 戦略を立てる波 |

### インジケーター設定

| パラメーター | デフォルト | 説明 |
|------------|----------|------|
| SMA_Period | 21 | 移動平均線の期間 |
| SR_Lookback_Bars | 50 | S/Rライン検出の遡り期間 |
| SR_Threshold | 0.0002 | S/Rレベル判定の閾値 |
| Cluster_Min_Bars | 10 | クラスター判定の最小足数 |
| Cluster_Range_Pips | 30 | クラスター判定の価格幅 |

### 時間設定

| パラメーター | デフォルト | 説明 |
|------------|----------|------|
| London_Start_Hour | 8 | ロンドンセッション開始時刻（GMT） |
| London_End_Hour | 16 | ロンドンセッション終了時刻（GMT） |

### アラート設定

| パラメーター | デフォルト | 説明 |
|------------|----------|------|
| Enable_Sound_Alert | true | サウンドアラートを有効化 |
| Enable_Popup_Alert | true | ポップアップアラートを有効化 |
| Alert_Cooldown_Seconds | 300 | アラートのクールダウン（秒） |

### 視覚設定

| パラメーター | デフォルト | 説明 |
|------------|----------|------|
| London_BG_Color | 濃紺 | ロンドン時間帯の背景色 |
| Order_BG_Color | 緑 | 秩序あり時の背景色 |
| SR_Line_Color | 黄色 | S/Rラインの色 |
| Cluster_Box_Color | 青 | クラスターボックスの色 |

## 使用方法

### 基本的なトレード戦略

1. **環境認識**
   - チャート左上の情報パネルを確認
   - 上位足と基準足のトレンド方向が一致しているか確認
   - 「秩序: あり（Order）」の表示を待つ

2. **時間帯の確認**
   - ロンドンセッション中（背景色が変化）であることを確認
   - 最高の条件：「★★★ 最高のエントリー環境 ★★★」

3. **エントリーポイントの特定**
   - S/Rライン（黄色の点線）付近での価格反応を観察
   - クラスターボックス（青）のブレイクアウトを確認
   - SMA（21期間）付近での反転を確認

4. **シグナルの確認**
   - アラートが鳴ったら、価格がSMA付近にあることを確認
   - トレンド方向に沿ったエントリーを検討

### 「守破離」の実践

- **守（Guard）**: S/Rラインやクラスターゾーンが「守られた」かを確認
- **破（Break）**: 短期トレンドのネックラインがブレイクされたか確認
- **離（Depart）**: ブレイク後に価格が勢いよく離れていくか確認

## 技術仕様

### 実装機能

1. **トレンド判定アルゴリズム**
   - SMAの傾きと価格位置の組み合わせ
   - 上昇・下降・中立の3状態判定

2. **S/R検出アルゴリズム**
   - スイングハイ/ローの自動検出
   - 類似レベルの統合（閾値ベース）

3. **クラスター検出**
   - 一定期間内の価格変動幅チェック
   - 最小足数と価格幅の条件判定

4. **時間フィルター**
   - GMT基準のロンドンセッション判定
   - 日付をまたぐ場合の対応
