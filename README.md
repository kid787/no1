# XAUUSD Fintokei Challenge EA

MT5用XAUUSD専用のFintokeiチャレンジプラン合格EA

## 概要

このEAは、Fintokeiチャレンジプラン（ステップ1およびステップ2）の評価ルールを完全に遵守し、自動的に合格条件を達成することを目的としています。

## 特徴

### トレードロジック

- **5分足デイトレード**: M5タイムフレームでのデイトレード戦略
- **XAUUSD専用**: 金/米ドルペアに最適化
- **グランビルの法則**: 200SMAと100EMAを使用した長期MAへの引き付けトレード
- **水平線/ネックライン反発**: サポート・レジスタンスレベルでの反発を検出
- **プライスアクション**: ピンバー、包み足、スター系パターンの認識
- **コンフルエンス戦略**: 2つ以上のシグナルが重なった場所でのみエントリー

### 資金管理ロジック（Fintokeiルール完全準拠）

- **1日の最大損失率監視（5%ルール）**: UTC 0時（日本時間9時）基準での日次損失制限
- **全体の最大損失率監視（10%ルール）**: 初期資金基準の総損失制限
- **最大リスク3%**: 同時オープンポジションのリスク制限
- **利益目標**: ステップ1: 8%、ステップ2: 6%
- **最低取引日数**: 3日間の取引日要件
- **30日活動要件**: 口座アクティブ維持のための自動監視

## インストール方法

1. `Experts/XAUUSD_Fintokei_EA.mq5` ファイルをMT5の `MQL5/Experts/` フォルダにコピー
2. MT5を再起動またはNavigatorを更新
3. XAUUSDチャートにEAをドラッグ＆ドロップ
4. パラメータを設定して「OK」をクリック

## パラメータ設定

### Trading Settings
| パラメータ | 説明 | デフォルト値 |
|-----------|------|-------------|
| TradingTimeframe | 取引タイムフレーム | M5 |
| SlowMAPeriod | 遅いMA期間（SMA） | 200 |
| FastMAPeriod | 速いMA期間（EMA） | 100 |
| SupportResistanceLookback | S/R検出期間 | 50 |
| MinConfluenceSignals | 最小コンフルエンスシグナル数 | 2 |

### Risk Management
| パラメータ | 説明 | デフォルト値 |
|-----------|------|-------------|
| RiskPerTrade | 1トレードあたりのリスク（%） | 1.0 |
| MaxRiskPercentage | 最大オープンリスク（%） | 3.0 |
| StopLossPips | ストップロス（pips） | 100 |
| TakeProfitRatio | リスク:リワード比率 | 2.0 |

### Fintokei Challenge Settings
| パラメータ | 説明 | デフォルト値 |
|-----------|------|-------------|
| ChallengeStep | チャレンジステップ（1または2） | 1 |
| InitialBalance | 初期資金（JPY） | 10,000,000 |
| DailyLossLimit | 日次損失制限（%） | 5.0 |
| TotalLossLimit | 総損失制限（%） | 10.0 |
| Step1ProfitTarget | ステップ1利益目標（%） | 8.0 |
| Step2ProfitTarget | ステップ2利益目標（%） | 6.0 |
| MinTradingDays | 最低取引日数 | 3 |
| SafetyBuffer | 安全バッファ（%） | 0.5 |

### Trading Hours
| パラメータ | 説明 | デフォルト値 |
|-----------|------|-------------|
| TradeStartHour | 取引開始時間（サーバー時間） | 9 |
| TradeEndHour | 取引終了時間（サーバー時間） | 22 |
| TradeOnMonday | 月曜日取引 | true |
| TradeOnFriday | 金曜日取引 | true |

## 使用上の注意

1. **バックテスト推奨**: 実運用前に十分なバックテストを実施してください
2. **デモ口座推奨**: まずはデモ口座での動作確認を行ってください
3. **パラメータ調整**: 市場状況に応じてパラメータの微調整が必要な場合があります
4. **監視**: EAは自動で動作しますが、定期的な監視を推奨します
