# ゴールド2本ローソク足パターンEA

MT4用のゴールド（XAUUSD）専用EA - 2本のローソク足パターンを使用したトレーディングシステム

## 概要

このEAは、1分足チャートで2本のローソク足の形状パターンを分析し、自動的にエントリーと決済を行います。

### トレードロジック

**エントリー条件（買い）：**
1. 2本目のローソク足が陰線、1本目が陽線
2. 1本目の安値（ひげ）が2本目の安値より低い（下に突き抜けている）
3. 両方のローソク足の実体が十分なサイズ
4. 勝率向上フィルター：
   - 1本目の高値が2本目より低い、または
   - 1本目の上ひげが短い

**エグジット条件：**
- 利益が出ている時のみ、陰線の実体完成で利確
- 損失中は陰線でも利確見送り
- リスクリワード1.5のテイクプロフィット到達
- トレーリングストップ（20SMA基準）

**リスク管理：**
- 資金の2%でロット計算
- ストップロス：直近安値（抵抗ゾーン）
- テイクプロフィット：リスクリワード1.5
- 最大同時保有ポジション：2

## インストール方法

1. MT4を開く
2. `ファイル` → `データフォルダを開く`
3. `MQL4` → `Experts` フォルダに `GoldTwoCandlePattern.mq4` をコピー
4. MT4を再起動するか、ナビゲーターウィンドウで右クリック → `更新`

## 使用方法

1. XAUUSD（ゴールド）の1分足チャートを開く
2. ナビゲーターから `GoldTwoCandlePattern` をチャートにドラッグ
3. パラメータを調整（デフォルトでも使用可能）
4. `自動売買を許可する` にチェックを入れる
5. `OK` をクリック

## パラメータ設定

| パラメータ | デフォルト値 | 説明 |
|----------|------------|------|
| RiskPercent | 2.0 | 1トレードあたりの資金リスク率(%) |
| RiskReward | 1.5 | リスクリワード比率 |
| MaxPositions | 2 | 最大同時保有ポジション数 |
| MinBodyPips | 5.0 | ローソク足実体の最小サイズ(pips) |
| MinLowDiffPips | 3.0 | 安値の最小差(pips) |
| UseWinRateFilter | true | 勝率向上フィルター使用 |
| UseTrailingStop | true | トレーリングストップ使用 |
| TrailingSMA_Period | 20 | トレーリングストップ用SMA期間 |
| LongOnly | true | ロングのみ（推奨） |
| MagicNumber | 12345 | マジックナンバー |
| Slippage | 30 | スリッページ(ポイント) |

## 推奨設定

- **通貨ペア**: XAUUSD（ゴールド）
- **タイムフレーム**: 1分足（M1）
- **口座タイプ**: 日本円口座
- **最小証拠金**: $1,000以上推奨
- **スプレッド**: 低スプレッド口座推奨

## 注意事項

- このEAは**ゴールド専用**に設計されています
- **1分足チャート**での使用を推奨します
- **ロングエントリーのみ**を推奨（売りはトレンド継続が弱い）
- バックテストとデモ口座で十分にテストしてから実運用してください
- 相場状況によっては損失が発生する可能性があります

## 機能詳細

### ローソク足パターン分析
- 2本のローソク足の形状を自動判定
- 実体とひげの長さを正確に計算
- 最小サイズ条件でフィルタリング

### リスク管理
- 口座残高の2%で自動ロット計算
- 直近安値を考慮したストップロス設定
- リスクリワード比率1.5のテイクプロフィット

### トレーリングストップ
- 20SMAを基準にトレーリング
- ローソク足実体がSMAを抜けたら更新
- 利益を保護しながら伸ばす

### 1時間足分析
- レジスタンスゾーンを自動検出
- レジスタンス接近時はエントリー見送り

## トラブルシューティング

**エントリーされない場合：**
- パラメータが厳しすぎる可能性：`MinBodyPips`や`MinLowDiffPips`を下げてみる
- 勝率フィルターを一時的に無効化（`UseWinRateFilter = false`）
- ログを確認して見送り理由をチェック

**ロット数が小さすぎる場合：**
- `RiskPercent`を上げる（ただしリスク増加）
- 口座残高を増やす

**スリッページエラーが出る場合：**
- `Slippage`パラメータを増やす（例：50）
