# MT5 ロット計算ユーティリティ (v2.0)

## 概要

MT5（MetaTrader 5）上で動作する**インタラクティブなロット計算インジケーター**です。
チャート上に**損切りライン（赤）**と**利確ライン（緑）**を表示し、ラインをドラッグして移動させることで、リアルタイムで最適なロットサイズ、リスクリワード比、想定利益を自動計算します。

## 目的

このツールは、トレーダーが適切な資金管理を実践するために設計されています。
特に以下の場合に有用です：

- **ボラティリティに応じた損切り幅**: ATRなどを使用した可変的な損切り設定
- **チャート根拠に基づく損切り**: 直近安値/高値などの重要ポイントまでの距離
- **リスク管理の徹底**: 常に口座残高の一定割合（1%または2%）以内にリスクを固定

## 主な機能

✓ **インタラクティブなライン操作**: チャート上で損切りライン・利確ラインをドラッグして自由に移動可能
✓ **リアルタイム計算**: ラインを動かすと即座にロットサイズを再計算
✓ **視覚的に分かりやすい**: 赤い損切りライン、緑の利確ラインで直感的に操作
✓ **リスクリワード表示**: 利確ラインに到達した場合のRR比と想定利益を自動計算
✓ **口座残高ベース**: 常に口座残高の指定割合（1%または2%）以内にリスクを固定
✓ **ブローカー対応**: 最小/最大/ステップサイズに自動対応
✓ **全通貨ペア対応**: クロス円・非クロス円ペアの両方に対応
✓ **カスタマイズ可能**: ラインの太さ、初期位置などを調整可能

## インストール方法

1. `LotCalculator.mq5` ファイルをMT5のインジケーターフォルダにコピーします：
   ```
   C:\Users\[ユーザー名]\AppData\Roaming\MetaQuotes\Terminal\[インスタンスID]\MQL5\Indicators\
   ```

2. MT5を起動し、メタエディター（MetaEditor）を開きます

3. `LotCalculator.mq5` をコンパイルします（F7キー）

4. チャートにインジケーターをドラッグ&ドロップするか、「挿入」→「インジケーター」→「カスタム」→「LotCalculator」から追加します

## パラメータ設定

### 入力パラメータ

| パラメータ名 | 変数名 | デフォルト値 | 説明 |
|------------|--------|------------|------|
| リスク許容度 (%) | RiskPercent | 2.0 | 1回のトレードで許容する最大損失の口座残高に対する割合（例: 1.0 = 1%, 2.0 = 2%） |
| 表示桁数 | LotDigits | 2 | 計算されたロットサイズの小数点以下の表示桁数 |
| 初期損切り幅 (Pips) | InitialSL_Pips | 30.0 | インジケーター起動時の損切りラインの初期位置（現在価格からのPips） |
| 初期利確幅 (Pips) | InitialTP_Pips | 90.0 | インジケーター起動時の利確ラインの初期位置（現在価格からのPips） |
| ラインの太さ (1-5) | LineWidth | 2 | 損切りライン・利確ラインの太さ（1=細い、5=太い） |

### パラメータ変更方法

1. チャート上でインジケーターを右クリック
2. 「LotCalculator」→「プロパティ」を選択
3. 「パラメーターの入力」タブで値を変更
4. 「OK」をクリック

## 使い方

### 基本操作

1. **インジケーターをチャートに追加**: チャートにアタッチすると、赤い損切りラインと緑の利確ラインが自動的に表示されます

2. **ラインを移動**:
   - 損切りライン（赤）をクリックしてドラッグし、任意の価格に移動
   - 利確ライン（緑）をクリックしてドラッグし、任意の価格に移動

3. **リアルタイム計算**: ラインを動かすと、即座にロット数、リスクリワード比、想定利益が再計算されます

### 表示内容

チャート左上に**2つの情報パネル**が表示されます：

#### パネル1: ロット計算結果（白色テキスト）

```
口座残高: 1000000.00 JPY

許容損失: 20000.00 JPY (2.0%)

推奨ロット: 2.00 Lot
最大損失額: 20000.00 JPY
```

#### パネル2: 利確ライン情報（緑色テキスト）

```

利確価格: 150.555
利確幅: 30.0 Pips
リスクリワード: 1:3.00

```

## 計算ロジック

### 1. 損切り幅の計算（自動）

損切りライン（赤）をドラッグして配置すると、現在価格との距離が自動的にPips単位で計算されます：

```
損切り幅 (Pips) = |現在価格 - 損切りライン価格| / Pipサイズ
```

### 2. 許容損失額の決定

```
許容損失額 = 口座残高 × (RiskPercent / 100)
```

例: 口座残高が100万円、リスク許容度が2%の場合
```
許容損失額 = 1,000,000 × 0.02 = 20,000円
```

### 3. 1ロットあたりの損失額の計算

現在の通貨ペア、損切り幅（Pips）、およびブローカーの取引条件を考慮し、
1ロット（100,000通貨単位）で取引した場合の損失額を計算します。

MQL5の `SymbolInfoDouble` 関数を使用して：
- `SYMBOL_TRADE_TICK_SIZE`: ティックサイズ
- `SYMBOL_TRADE_TICK_VALUE`: ティック値（口座通貨建て）
- `SYMBOL_POINT`: 最小価格変動単位

これらの値から、正確な1ロットあたりの損失額（円換算）を算出します。

### 4. 適正ロット数の決定

```
適正ロット数 = 許容損失額 / 1ロットあたりの損失額
```

例: 許容損失額が20,000円、1ロットあたりの損失額が10,000円の場合
```
適正ロット数 = 20,000 / 10,000 = 2.00ロット
```

### 5. ロットサイズ調整

計算結果を以下の制約に合わせて調整します：
- `SYMBOL_VOLUME_MIN`: ブローカーの最小ロットサイズ
- `SYMBOL_VOLUME_MAX`: ブローカーの最大ロットサイズ
- `SYMBOL_VOLUME_STEP`: ロットステップ（増減単位）

### 6. リスクリワード比と想定利益の計算

利確ライン（緑）の位置から自動計算されます：

```
利確幅 (Pips) = |利確ライン価格 - 現在価格| / Pipサイズ
リスクリワード比 = 利確幅 / 損切り幅
想定利益 = (利確幅のロット当たり利益) × 推奨ロット数
```

## 使用例

### シナリオ1: サポートラインでのロングエントリー

**状況**: USD/JPYが150.000のサポートラインで反発を狙う

**操作**:
1. 現在価格: 150.000
2. 損切りライン（赤）を直近安値の149.800にドラッグ → 損切り幅20 Pips
3. 利確ライン（緑）を直近レジスタンスの150.600にドラッグ → 利確幅60 Pips

**結果** (口座残高100万円、リスク2%):
- 推奨ロット: 1.00 Lot
- 最大損失: 20,000円
- リスクリワード: 1:3.00
- 想定利益: 60,000円

### シナリオ2: ブレイクアウト戦略（広めの損切り）

**状況**: EUR/USDの重要レジスタンスブレイク

**操作**:
1. 現在価格: 1.10000
2. 損切りライン（赤）をブレイクポイント下の1.09500にドラッグ → 損切り幅50 Pips
3. 利確ライン（緑）を次のレジスタンス1.11000にドラッグ → 利確幅100 Pips

**結果** (口座残高50万円、リスク2%):
- 推奨ロット: 0.20 Lot
- 最大損失: 10,000円
- リスクリワード: 1:2.00
- 想定利益: 20,000円

### シナリオ3: スキャルピング（狭い損切り）

**状況**: USD/JPYの短期トレード

**操作**:
1. 現在価格: 150.500
2. 損切りライン（赤）を150.400にドラッグ → 損切り幅10 Pips
3. 利確ライン（緑）を150.700にドラッグ → 利確幅20 Pips

**結果** (口座残高200万円、リスク2%):
- 推奨ロット: 4.00 Lot
- 最大損失: 40,000円
- リスクリワード: 1:2.00
- 想定利益: 80,000円

## 注意事項

1. **リアルタイム更新**: ラインをドラッグするとリアルタイムで計算が更新されます。また、1秒ごとに自動更新されます

2. **ライン操作**:
   - 損切りライン（赤）と利確ライン（緑）をマウスでドラッグして自由に移動できます
   - ラインをクリックすると選択状態になり、移動可能になります
   - ラインの太さは入力パラメータで調整できます（1-5）

3. **クロス円以外の通貨ペア**: EUR/USDなどの非円建てペアでも、自動的に口座通貨（JPY）に換算して計算します

4. **ブローカーによる違い**: 最小ロット、最大ロット、ロットステップはブローカーにより異なります。本インジケーターは自動的にこれらの制約に対応します

5. **資金管理の重要性**: このツールは適切なロットサイズを提案しますが、最終的な判断はトレーダー自身が行ってください

6. **複数チャートでの使用**: 各チャートに独立してインジケーターをアタッチできます。それぞれのチャートで独自のラインを設定できます

## トラブルシューティング

### ラインが表示されない場合

- インジケーターを再起動してください（チャートから削除して再度追加）
- チャートを右クリック→「更新」を選択
- MT5を再起動してください

### ラインが動かせない場合

- ラインをクリックして選択状態にしてからドラッグしてください
- チャートのオブジェクトロックが有効になっていないか確認してください
- 「チャート」→「オブジェクト」→「オブジェクトリスト」で、LC_StopLossとLC_TakeProfitが存在するか確認

### 計算結果が表示されない場合

- チャートの左上を確認してください（2つの情報パネルが表示されます）
- インジケーターを再起動してください
- エキスパートログ（Ctrl+T）でエラーメッセージを確認してください

### ロット数が非常に小さい、または0.00と表示される場合

- 口座残高が少なすぎる、または損切り幅が広すぎる可能性があります
- 損切りラインを現在価格に近づけて損切り幅を狭くしてください
- リスク許容度を上げることも検討してください（ただし慎重に）

### リスクリワード比が正しくない場合

- 利確ラインが現在価格より上（ロングの場合）、または下（ショートの場合）にあるか確認
- ラインを再配置してみてください

### 計算結果が正しくない場合

- ブローカーのシンボル設定を確認してください
- デモ口座で動作テストを行ってください
- 異なる通貨ペアで試してみてください
