## 1. FintokeiRiskManager.mq5

**リスク管理専用EA** - 他のEAや手動取引と併用可能

### 機能
- 有効証拠金（Equity）のリアルタイム監視
- 全体損失率（10%）・日次損失率（5%）の監視
- 損失ラインに到達した場合の全ポジション緊急決済
- UTC 0時（日本時間9時）の日次基準額自動リセット
- 取引日数カウント（最低3日間必要）
- チャート上へのステータス表示

### パラメータ
| パラメータ名 | デフォルト値 | 説明 |
|-------------|-------------|------|
| InitialBalance | 100000.0 | 初期残高（全体損失率の基準） |
| DailyLossLimitPct | 5.0 | 1日の最大損失率（%） |
| OverallLossLimitPct | 10.0 | 全体の最大損失率（%） |
| SafetyBufferPct | 0.1 | 安全バッファ（%）- 制限の手前で発動 |

### 使い方
1. MT5のチャートにEAをアタッチ
2. InitialBalanceにチャレンジプランの初期残高を設定
3. 他のEAや手動取引を行う
4. 損失制限に達すると自動的に全ポジション決済

## 2. FintokeiGranvilleEA.mq5

**グランビル法則 + Fintokeiリスク管理統合EA** - XAUUSD専用自動売買

### 機能
- グランビルの法則（Rule 1-7）に基づくエントリー
- 75期間・200期間EMAを使用したトレンド判定
- H4時間足でのMTFトレンド確認
- ADX・ATRフィルター
- ブレイクイーブン機能
- 部分利確機能
- 時間帯フィルター
- Fintokei損失制限の完全統合

### 特徴
- 1トレードのリスクを自動調整（Fintokei制限を超えないよう）
- 残りマージンの50%を上限としたリスク管理
- 緊急時の全ポジション自動決済

### パラメータ（主要なもの）
| パラメータ名 | デフォルト値 | 説明 |
|-------------|-------------|------|
| Symbol_to_Trade | XAUUSD | 取引対象銘柄 |
| Risk_Percent | 1.0 | 1トレードのリスク（残高の%）※控えめ推奨 |
| TakeProfit_Ratio | 2.0 | リスクリワード比率 |
| BreakEven_Enable | true | ブレイクイーブン機能 |
| PartialTP_Enable | true | 部分利確機能 |

## 3. FintokeiLotCalculator.mq5

**Fintokei対応ロット計算インジケーター** - 手動取引支援

### 機能
- ドラッグ可能なSL/TPラインで視覚的にロット計算
- Fintokei制限を考慮した安全なロットサイズ提案
- 全体・日次損失状況のリアルタイム表示
- リスクリワード比・期待利益の表示

### 使い方
1. チャートにインジケーターをアタッチ
2. マゼンタ（損切り）とライム（利確）のラインをドラッグ
3. 推奨ロットサイズがチャート上に表示される
4. Fintokei制限により制限されている場合はオレンジ色で警告

---

## Fintokeiチャレンジプランのルール

### 損失制限
- **全体損失率**: 初期資金の10%未満（例: 100万円 → 90万円を下回ったら失格）
- **日次損失率**: UTC 0時時点のEquityの5%未満

### 重要なポイント
1. 有効証拠金（Equity）が基準 - 含み益/損、スワップも含む
2. UTC 0時 = 日本時間 午前9時
3. 少しでも失格ラインを下回ると即失格
4. 最低3日間の取引が必要

## 推奨設定

### 安全性重視（推奨）
```
Risk_Percent = 1.0        # 1トレード1%リスク
SafetyBufferPct = 0.5     # 0.5%のバッファ
TakeProfit_Ratio = 2.0    # RR 1:2
```

### 標準設定
```
Risk_Percent = 2.0        # 1トレード2%リスク
SafetyBufferPct = 0.1     # 0.1%のバッファ
TakeProfit_Ratio = 1.5    # RR 1:1.5
```

## 注意事項

1. **バックテスト推奨**: 本番使用前に必ずバックテストとデモ口座でのテストを行ってください
2. **ブローカー依存**: ティックバリューやスプレッドはブローカーにより異なります
3. **スリッページ**: 急変動時はスリッページが発生する可能性があります
4. **EA重複**: FintokeiRiskManagerと他のEAを同時使用する場合、同一チャートでは動作しません

## インストール方法

1. MT5のデータフォルダを開く（ファイル → データフォルダを開く）
2. `MQL5/Experts/` に `.mq5` ファイルをコピー
3. `MQL5/Indicators/` にインジケーターファイルをコピー
4. MT5を再起動、またはナビゲーターで右クリック→更新
5. コンパイル（F7）してエラーがないことを確認
