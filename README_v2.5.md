# ゴールド（XAUUSD）ロング専用EA v2.5

## 概要
2本のローソク足パターンを使用したゴールド専用の押し目買い戦略EA

**バージョン 2.5の新機能:**
- ✨ **トレーリングストップ機能** - 利益を自動保護
- 📊 **レジスタンスゾーンの視覚化** - チャート上に水平線表示
- ⏰ **時間帯フィルター** - 取引時間帯を制限
- 📈 **リアルタイム統計パネル** - 勝率・利益を常時表示
- 🛡️ **エラーハンドリング強化** - より安定した動作

**バージョン 2.0からの継続機能:**
- 複数時間足対応（15分足 & 1時間足）
- 1時間足レジスタンスゾーン検出機能
- レジスタンスゾーンでの自動利確

## 新機能の詳細

### 1. トレーリングストップ機能

利益が出たポジションの損切りラインを自動的に引き上げ、利益を保護します。

**設定パラメータ:**
- **UseTrailingStop**: トレーリングストップ使用（デフォルト：true）
- **TrailingStop_Points**: トレーリングストップ幅（デフォルト：200pt = 20ドル）
- **TrailingStep_Points**: 更新ステップ（デフォルト：50pt = 5ドル）
- **TrailingStart_Points**: 開始利益（デフォルト：300pt = 30ドル）

**動作例:**
1. エントリー後、30ドルの利益が出たらトレーリング開始
2. 現在価格から20ドル下に損切りラインを自動設定
3. 価格が上昇するたびに、5ドル以上の利益増加で損切りラインも引き上げ

### 2. レジスタンスゾーンの視覚化

1時間足で検出したレジスタンスゾーンをチャート上に赤い水平線で表示します。

**設定パラメータ:**
- **ShowResistanceLines**: レジスタンスライン表示（デフォルト：true）
- **ResistanceColor**: ライン色（デフォルト：赤）
- **LineWidth**: ライン幅（デフォルト：2）

**表示内容:**
- 3回以上タッチされた価格帯を水平線で表示
- マウスオーバーでタッチ回数を表示
- 利確目標として活用可能

### 3. 時間帯フィルター

取引を行う時間帯を制限できます。

**設定パラメータ:**
- **UseTimeFilter**: 時間帯フィルター使用（デフォルト：false）
- **StartHour**: 取引開始時刻（デフォルト：0時）
- **EndHour**: 取引終了時刻（デフォルト：23時）
- **AvoidWeekend**: 週末取引を避ける（デフォルト：true）

**使用例:**
- ロンドン時間のみ取引：StartHour=8, EndHour=17（GMT）
- ニューヨーク時間のみ：StartHour=13, EndHour=22（GMT）
- アジア時間除外：StartHour=8, EndHour=23

### 4. リアルタイム統計パネル

チャート左上にEAの統計情報を常時表示します。

**表示内容:**
- 総トレード数
- 勝ち/負けトレード数
- 勝率（%）
- 総利益（USD）
- 現在のポジション状態
- 現在の利益
- レジスタンスまでの距離

**設定パラメータ:**
- **ShowInfoPanel**: 情報パネル表示（デフォルト：true）

## 戦略の特徴

### エントリー条件（ロングのみ）

#### 時間足設定
- **監視時間足**: M15（15分足）とH1（1時間足）
- **エントリー判定**: デフォルトでは両方の時間足でシグナル確認が必要
- パラメータ `RequireBothTimeframes` で変更可能

#### パターン検出条件
1. **ローソク足パターン**
   - 1本目：陰線
   - 2本目：陽線

2. **安値の確認**
   - 2本目の安値（Low）が1本目より明確に下にある
   - デフォルト：80ポイント（0.8ドル）以上の差

3. **実体サイズ**
   - 両方のローソク足が一定以上の実体サイズを持つ
   - デフォルト：30ポイント（0.3ドル）以上

4. **勝率フィルター（オプション）**
   - 2本目の高値が1本目より低い
   - 2本目の上ひげが短い（デフォルト：50ポイント以下）

### 決済条件（優先順位）

#### 1. レジスタンスゾーン利確（最優先）
- **レジスタンスゾーン検出**: 1時間足の過去100本分の高値を分析
- **判定条件**: 同じ価格帯（±50ポイント）に3回以上タッチ
- **利確条件**:
  - 現在価格がレジスタンスゾーン（±20ポイント以内）に到達
  - かつ、利益が出ている状態
  - 条件を満たせば即座に決済

#### 2. トレーリングストップ（NEW）
- 利益が30ドルに達したら自動的に損切りラインを引き上げ
- 現在価格から20ドル下に損切りを維持
- 利益を確保しながら更なる上昇を狙う

#### 3. 条件付き利確（補助）
- 利益が出ている状態で陰線の実体が完成したら決済
- 損失状態では陰線が出ても決済しない

#### 4. 固定損切り
- エントリーした2本目の安値から35ドル（350ポイント）下に固定
- トレーリングストップ開始後は動的に変更

## 全パラメータ一覧

### 基本設定
- **LotSize**: ロットサイズ（デフォルト：0.01）

### エントリー条件
- **MinWickDifference_Points**: 安値の最小差（デフォルト：80ポイント）

- **UseHighFilter**: 勝率フィルター使用（デフォルト：true）

- **ResistanceZoneRange_Points**: レジスタンスゾーン判定範囲（デフォルト：±50ポイント）
- **MinResistanceTouches**: レジスタンス判定の最小タッチ回数（デフォルト：3回）
- **ResistanceExitRange_Points**: レジスタンス到達判定範囲（デフォルト：±20ポイント）

### 時間帯フィルター（NEW）

## 使い方

### 1. MT5へのインストール
```
MT5のデータフォルダ → MQL5 → Experts → GoldLongEA_v2.5.mq5 をコピー
```

### 2. コンパイル
- MetaEditorで GoldLongEA_v2.5.mq5 を開く
- F7キーでコンパイル
- エラーがないことを確認

### 3. チャートに適用
- XAUUSDのチャートを開く
- 推奨時間足：M15（15分足）またはH1（1時間足）
- ナビゲーターから GoldLongEA_v2.5 をチャートにドラッグ
- **重要**: どちらの時間足でも動作しますが、両方の時間足データが必要です

### 4. パラメータ調整
- 必要に応じてパラメータを調整
- 初心者は�デフォルト設定から開始推奨
- バックテストで最適化してから実運用

### 5. 視覚確認
- レジスタンスラインがチャート上に表示されることを確認
- 左上に統計パネルが表示されることを確認
- ポジションを持つとリアルタイムで利益が更新される

## 注意事項

1. **ゴールド専用**
   - このEAはXAUUSD（ゴールド）に最適化されています
   - 他の通貨ペアでは使用しないでください

2. **ポイント計算**
   - ゴールドは100ポイント = 1ドル
   - スプレッドは30〜50ポイント程度を想定

3. **リスク管理**
   - 必ず少額ロットでテストしてください
   - バックテストで戦略を検証してから実運用してください
   - トレーリングストップを使用する場合、利益確保と伸ばすのバランスを調整

4. **推奨環境**
   - 時間足：M15またはH1
   - VPS使用推奨（24時間稼働、トレーリングストップに必須）
   - 低スプレッドのブローカー推奨

5. **表示設定**
   - 複数チャートで同じEAを動かす場合、情報パネルが重なることがあります
   - ShowInfoPanel = false で非表示にできます

## トラブルシューティング

### レジスタンスラインが表示されない
- ShowResistanceLines = true に設定
- 1時間足データが十分にあるか確認（最低100本以上）
- チャートを更新（F5キー）

### 統計パネルが表示されない
- ShowInfoPanel = true に設定
- チャート左上のスペースを確認
- 他のインジケーターと重なっていないか確認

### トレーリングストップが動作しない
- UseTrailingStop = true に設定
- VPSまたは常時稼働環境で動作させる
- TrailingStart_Points 以上の利益が出ているか確認

### エントリーシグナルが出ない
- 両方の時間足データが揃っているか確認
- RequireBothTimeframes = false にして片方の時間足だけでテスト
- ログでエントリー見送り理由を確認
